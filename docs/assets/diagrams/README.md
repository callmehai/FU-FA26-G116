# Sơ đồ Mermaid dùng trong tài liệu

Các sơ đồ trong nhóm này có source Mermaid (`.mmd`) và ảnh PNG xuất cùng tên. Hiện thư mục con
[meeting-management/](meeting-management/README.md) chứa các sơ đồ gửi duyệt, duyệt và công bố cuộc họp.

Sửa source `.mmd` trước, sau đó cập nhật PNG tương ứng và kiểm tra các tài liệu đang nhúng ảnh. README
của thư mục con liệt kê từng sơ đồ và ngữ cảnh nghiệp vụ.
