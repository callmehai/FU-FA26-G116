# Wireframe luồng cuộc họp

[luong-cuoc-hop.html](luong-cuoc-hop.html) là prototype HTML tĩnh để xem wireframe theo luồng nghiệp vụ.
Mở file bằng trình duyệt để xem. Đây là tài liệu tham khảo giao diện, không phải frontend chạy thật,
không gọi API và không lưu dữ liệu.

Khi cập nhật wireframe, đối chiếu luồng tại [09-bussinessflow](../../09-bussinessflow/README.md) và
quyết định giao diện [ADR-0012](../../05-decisions/0012-giao-dien-hanh-chinh-sidebar-doc.md). Không
coi prototype này là nguồn thay thế cho UI đang chạy.
