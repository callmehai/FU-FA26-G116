Cách qua: giữ container `trustcabinet-postgres` của `docker compose`, dựng thêm `alpine/socat` tên `pgforward` (`--network trustcabinet_default -p 127.0.0.1:15432:5432` tới `trustcabinet-postgres:5432`), rồi chạy test với `TRUSTCABINET_TEST_CONNECTION_STRING="Host=127.0.0.1;Port=15432;Database=trustcabinet;Username=trustcabinet;Password=<.env>"`. Ngoài ra đã `ALTER USER trustcabinet PASSWORD` trong container cho khớp `.env` (trước đó container cũng từ chối mật khẩu `.env` qua TCP). Container `pgforward` đang chạy — agent xong việc có thể giữ hoặc xóa.
