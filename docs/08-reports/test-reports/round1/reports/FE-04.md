## 2. Từng case đã sửa nội dung

### IT13 — `Verify POST /api/meetings answers 400 for a body that is not valid JSON` (tôi sửa)

- Trước: `HTTP 400 Bad Request, code "MSG31", no "errors" map.` + `No meeting is created.`
- Sau: `HTTP 400 Bad Request with an empty body: the framework rejects the malformed JSON
  before the endpoint runs, so no MSG31 envelope is returned.` + `No meeting is created.`
- Lý do: **case sai so với code**. `POST /api/meetings` dùng `[FromBody]` binding
  (`MeetingEndpoints.cs:444-447`): JSON hỏng bị framework từ chối với 400 rỗng trước khi vào
  endpoint. Chỉ đường `PUT` mới tự parse và trả MSG31 (`MeetingEndpoints.cs:557-580`), đúng như
  docs `03-api/05-quan-ly-cuoc-hop.md` dòng 476-478 ("POST JSON lỗi cũng trả 400" — không hứa mã).
  Bằng chứng: test mới `Post_rejects_a_body_that_is_not_valid_json` fail lần đầu với body rỗng,
  pass sau khi sửa case + test assert `400 + body rỗng + không tạo meeting`.
- Procedure/Pre-conditions giữ nguyên.
