# Meeting Management — UI (FE-04, MEET)

Requirement: Meeting lifecycle through the screens: create, edit and reschedule, list and detail, submit, approve or reject, publish, start, end and cancel.

Precondition: Test build of frontend + backend; Organizer (MeetingCreator), Approver (MeetingApprover), Chair, Secretary, Member and administrator accounts supplied by QA lead; meetings prepared in each status; a second browser for the two-user cases; a way to make the backend fail for the error cases.
