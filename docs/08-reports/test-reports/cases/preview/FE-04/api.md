# Meeting Management — API (FE-04, MEET)

Requirement: Meeting create, update, list, detail, readiness, status transitions and status history.

Precondition: Test build of backend with Postman or curl; role accounts supplied by QA lead: Organizer (MeetingCreator), Approver (MeetingApprover), Chair, Secretary, Member, an administrator (AdminUsers) and an unrelated account; meetings prepared in each status; a way to make the database fail for the 503 cases.
