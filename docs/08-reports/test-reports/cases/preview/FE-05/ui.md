# Agenda — UI (FE-05, AGENDA)

Requirement: Agenda tab: view, add, edit, delete and reorder items, set the current item, complete an item and record its conclusion.

Precondition: Test build of frontend + backend; Chair, Secretary, Member and administrator accounts and a Guest invitation supplied by QA lead; meetings prepared in each status with agenda items; a second browser for the two-user cases; a way to make the backend fail for the error cases.
