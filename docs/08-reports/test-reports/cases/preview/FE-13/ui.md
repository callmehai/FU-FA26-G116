# Notifications — UI (FE-13, NOTI)

Requirement: Notification bell and panel, mark as read, open the target, real-time delivery, and the emails the workflow sends.

Precondition: Test build of frontend + backend; participant, Organizer and administrator accounts supplied by QA lead; Approved and Published meetings; mailboxes for the invitees; Chrome and a second browser profile for the two-user cases.
