# Notifications — API (FE-13, NOTI)

Requirement: Notification list, unread count, read state and target endpoints, and the email delivery webhook.

Precondition: Backend running on the test build (GET /api/health answers 200). Participant accounts supplied by QA lead, with notifications created by publishing meetings; an Organizer to publish and change meetings; an administrator to deactivate accounts. For the webhook: the Resend webhook secret and a sent email row, supplied by QA lead.
