# Transcription & Summary — API (FE-10, TRANS)

Requirement: Transcription, transcript editing, speaker attribution, summary, Voice ID, voice collection and AI settings endpoints.

Precondition: Backend running on the test build (GET /api/health answers 200). Chair, Secretary and Member accounts supplied by QA lead; a meeting in the needed status with the needed roster and recording; an Administrator with AdminUsers; an enrolled participant for Voice ID cases; a controlled inbox for Guest invitations. QA lead can stop the speech worker and the AI server.
