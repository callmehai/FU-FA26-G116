# Transcription & Summary — UI (FE-10, TRANS)

Requirement: Transcript view, edit and speaker attribution, the AI summary draft (generate, view, edit, approve), Voice ID with consent, voice samples collected by the Secretary, and the AI settings screen.

Precondition: Test build of frontend + backend; Chair, Secretary, Member and Administrator accounts supplied by QA lead; meetings in the needed status with recordings, transcripts, sentences and Voice ID consent as each case says; the speech worker and the AI server running (QA lead can stop them); microphone permission in the browser for recording cases; Chrome and a second browser for the two-user cases.
