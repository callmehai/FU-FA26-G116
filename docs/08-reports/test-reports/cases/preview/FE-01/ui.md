# Authentication — UI (FE-01, AUTH)

Requirement: Sign-in with password and Google, session restore, sign-out and Guest access through an invitation link, exercised through the browser against the real backend.

Precondition: Test build of frontend + backend; role accounts supplied by QA lead; a controlled inbox for Guest invitations; Chrome and a second browser.
