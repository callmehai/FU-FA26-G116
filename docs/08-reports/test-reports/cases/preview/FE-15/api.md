# Reporting — API (FE-15, RPT)

Requirement: Meeting report and export endpoints.

Precondition: Test build of backend + frontend; an Organizer, a Member, an Administrator account and a Guest invitation link supplied by QA lead; meetings in several statuses and months for the Organizer; QA lead can read the audit log and stop the database; Postman or curl.
