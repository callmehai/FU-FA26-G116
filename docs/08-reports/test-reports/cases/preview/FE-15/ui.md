# Reporting — UI (FE-15, RPT)

Requirement: Meeting report: choose the period, read the figures and export.

Precondition: Test build of frontend + backend; Organizer, Member and Administrator accounts supplied by QA lead; meetings in several statuses and months for the Organizer; Chrome and a second browser for the two-user cases; Excel.
