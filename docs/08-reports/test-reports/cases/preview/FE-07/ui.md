# Documents — UI (FE-07, DOC)

Requirement: Personal library (upload, rename, move, delete, folders), the Admin view of a locked account's library, meeting documents (add, remove, link to agenda items, view, download), comments and read confirmation.

Precondition: Test build of frontend + backend; accounts supplied by QA lead: an Owner with a personal library, a Chair, a Secretary, a Member and an Organizer of one meeting, an Administrator with AdminUsers and a deactivated user with a library, a verified Guest invitation. Sample PDF and DOCX files; QA lead can inject store and database failures and end or cancel a meeting. Chrome and a second browser for the two-user cases.
