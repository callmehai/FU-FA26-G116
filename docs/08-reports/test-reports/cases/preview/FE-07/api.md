Requirement: Personal library, folder, meeting document, agenda link, comment and read confirmation endpoints.

Precondition: Backend running on the test build (GET /api/health answers 200). Accounts supplied by QA lead: an Owner (any active internal user), a Secretary, a Chair and a Member of one meeting, an Administrator with AdminUsers, and a deactivated user with a library. Sample PDF and DOCX files; QA lead can inject file store and database failures. A verified Guest invitation for the Guest cases.
