# Voting — UI (FE-11, VOTE)

Requirement: Votes tab: list and results, create and configure drafts, vote documents, open, cast (internal and Guest), close and record the conclusion.

Precondition: Test build of frontend + backend; Chair, Secretary and Member accounts supplied by QA lead; a meeting the Chair chairs, in the needed status, with the needed roster. Chrome and a second browser for the two-user cases.
