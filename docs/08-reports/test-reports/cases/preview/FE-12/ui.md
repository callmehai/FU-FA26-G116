# Minutes — UI (FE-12, MIN)

Requirement: Minutes tab: generate the draft from the fixed template, view, edit with preview, export to Word, submit, approve and issue, return for revision, and correct issued minutes.

Precondition: Test build of frontend + backend; Chair, Secretary, Member and Outsider accounts supplied by QA lead; a meeting in the needed status with its minutes in the needed state; Chrome and a second browser for the two-user cases; Word and a PDF reader.
