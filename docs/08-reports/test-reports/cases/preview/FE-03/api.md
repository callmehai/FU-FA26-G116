# Access Control — API (FE-03, RBAC)

Requirement: Role, capability matrix and audit log endpoints, and the 401/403/404 rules they enforce.

Precondition: Backend running on the test build (GET /api/health answers 200). An Administrator account holding AdminUsers and a Secretary account without it, supplied by QA lead; the four built-in roles ("Chủ toạ", "Thư ký", "Thành viên", "Quản trị viên") and a few custom roles; some audit-log entries written by earlier actions.
