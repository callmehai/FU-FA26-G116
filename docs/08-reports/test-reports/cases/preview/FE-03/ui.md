# Access Control — UI (FE-03, RBAC)

Requirement: Role and permission matrix, role management, audit log, and the capability gate on screens and endpoints.

Precondition: Test build of frontend + backend; an Administrator account (AdminUsers), a Secretary and a Member account without it supplied by QA lead; the four built-in roles ("Chủ toạ", "Thư ký", "Thành viên", "Quản trị viên") plus a custom role; audit-log entries from earlier actions. Chrome and a second browser for the two-user cases.
