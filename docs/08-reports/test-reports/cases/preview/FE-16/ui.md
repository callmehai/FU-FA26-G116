# Calendar — UI (FE-16, CAL)

Requirement: Working calendar, calendar sharing (request, share, respond, change, withdraw, end), the shared week and finding a meeting time.

Precondition: Test build of frontend + backend; Organizer accounts A, B and C with MeetingCreator, a Member without MeetingCreator and an administrator, supplied by QA lead; meetings in several statuses and levels to produce busy time; Chrome and a second browser profile for the two-user cases.
