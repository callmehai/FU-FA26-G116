# User Management — UI (FE-02, USER)

Requirement: Administration of user accounts: list and search, create, update, deactivate and reactivate, role assignment and password reset by email link.

Precondition: Test build of frontend + backend; an Administrator account (AdminUsers), a Secretary account without it, and target accounts in the needed state (active, deactivated, Google-only, with and without a password) supplied by QA lead. A controlled inbox for password-reset emails; Chrome and a second browser for the two-user cases.
