# User Management — API (FE-02, USER)

Requirement: User account endpoints for the System Admin and the public password-reset completion.

Precondition: Backend running on the test build (GET /api/health answers 200). An Administrator account holding AdminUsers, a Secretary account without it, and target accounts in the needed state (active, deactivated, Google-only) supplied by QA lead. A controlled inbox for password-reset emails.
