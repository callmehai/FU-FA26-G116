# Online Room — API (FE-08, ROOM)

Requirement: Call room, LiveKit webhook, requests to speak and meeting notes endpoints.

Precondition: Backend running on the test build (GET /api/health answers 200) with LiveKit configured. Chair, Secretary, Member, Organizer and Admin accounts supplied by QA lead; an InProgress Online meeting with that roster; a verified Guest session (UC-04); read-only database access and a LiveKit webhook signing helper held by the QA lead. Postman or curl.
