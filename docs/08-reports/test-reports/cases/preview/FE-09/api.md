# Recording — API (FE-09, REC)

Requirement: Recording, take, upload part, playback, download and speech clip endpoints.

Precondition: Backend running on the test build (GET /api/health answers 200). Active Chair, Secretary and Member accounts supplied by QA lead; meetings in the needed mode (InPerson, Online, Hybrid) and status; a user outside the participant list; a Guest invitation for the Guest cases; the speech worker running unless a case says otherwise. Recordings are personal data: consent, retention and erasure are checked where they apply.
