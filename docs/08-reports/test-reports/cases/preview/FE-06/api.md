# Participants — API (FE-06, PART)

Requirement: Participant, Guest invitation, invitation response, attendance and chair handover endpoints.

Precondition: Backend running on the test build (GET /api/health answers 200). Admin, Organizer, Chair, Secretary and Member accounts supplied by QA lead; a meeting in the needed status with the needed roster; a Guest with a verified session and a controlled inbox for Guest invitations where a case needs them.
