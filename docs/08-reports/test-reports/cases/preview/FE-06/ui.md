# Participants — UI (FE-06, PART)

Requirement: Participants tab: view, add internal people, invite and revoke Guests, change roles and rights, respond to the invitation, response status, attendance and chair handover.

Precondition: Test build of frontend + backend; Admin, Organizer, Chair, Secretary and Member accounts supplied by QA lead; a meeting in the needed status with the needed roster; a Guest invitation with a controlled inbox where a case needs it. Chrome and a second browser for the two-user cases.
