# Biên bản họp nhóm

Mỗi buổi họp một DOCX, tên `Meeting_Minutes_<dd_mm_yyyy>_<buổi>.docx` (chỉ dùng dấu `_`, không dùng `-`). Đẩy lên Drive bằng
`python scripts/push_reports.py minutes`; file trên Drive còn mang tên cũ có ngày `dd-mm-yyyy` được
đổi tên theo, không tạo bản thứ hai.

Quy tắc sửa và đồng bộ: [README của nguồn report](../README.md).
