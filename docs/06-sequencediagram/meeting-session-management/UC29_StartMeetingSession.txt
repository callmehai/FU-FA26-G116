title UC-29 - Start Meeting Session

actor "Chair" as Chair
boundary "Meeting Management Page" as MeetingPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
participant ":Meeting Participant Repository" as MeetingParticipantRepository
participant ":Meeting Session Repository" as MeetingSessionRepository
database ":Database" as Database

Chair->MeetingPage: Start Meeting Session
activate MeetingPage

MeetingPage->MeetingController: Start Meeting Session
activate MeetingController

MeetingController->MeetingService: startMeetingSession(sessionId, chairId)
activate MeetingService

MeetingService->MeetingSessionRepository: Get selected Meeting Session
activate MeetingSessionRepository

MeetingSessionRepository->Database: Retrieve Meeting Session
activate Database

Database-->MeetingSessionRepository: Meeting Session
deactivate Database

MeetingSessionRepository-->MeetingService: Meeting Session
deactivate MeetingSessionRepository

MeetingService->MeetingRepository: Get parent meeting
activate MeetingRepository

MeetingRepository->Database: Retrieve meeting
activate Database

Database-->MeetingRepository: Meeting
deactivate Database

MeetingRepository-->MeetingService: Meeting
deactivate MeetingRepository

MeetingService->MeetingParticipantRepository: Verify active Chair and Secretary assignments\n(BR-63, BR-89)
activate MeetingParticipantRepository

MeetingParticipantRepository->Database: Find Chair and Secretary assignments
activate Database

Database-->MeetingParticipantRepository: Assignment result
deactivate Database

MeetingParticipantRepository-->MeetingService: Assignment result
deactivate MeetingParticipantRepository

MeetingService->MeetingService: Validate Meeting is InProgress and\nSession is Planned (BR-58, BR-63, BR-89)

alt Meeting is not InProgress, Session is not Planned,\nor Chair is no longer assigned - EX-2
    MeetingService-->MeetingController: MSG58 - This meeting session cannot be started
    deactivate MeetingService

    MeetingController-->MeetingPage: Return session start failure
    deactivate MeetingController

    MeetingPage-->Chair: MSG58 - This meeting session cannot be started

else Session can be started
    MeetingService->MeetingSessionRepository: Check other InProgress Meeting Session\n(BR-59)
    activate MeetingSessionRepository

    MeetingSessionRepository->Database: Find InProgress Meeting Session
    activate Database

    Database-->MeetingSessionRepository: Active Session / None
    deactivate Database

    MeetingSessionRepository-->MeetingService: Active Session / None
    deactivate MeetingSessionRepository

    alt Another Meeting Session is already InProgress - EX-1
        MeetingService-->MeetingController: MSG57 - Another meeting session is already in progress.\nEnd it before starting another session
        deactivate MeetingService

        MeetingController-->MeetingPage: Return session start failure
        deactivate MeetingController

        MeetingPage-->Chair: MSG57 - Another meeting session is already in progress.\nEnd it before starting another session

    else No other Meeting Session is InProgress
        MeetingService->MeetingSessionRepository: Set status = InProgress and record actual start time\n(BR-58; BR-59 re-checked at write time)
        activate MeetingSessionRepository

        MeetingSessionRepository->Database: Update Meeting Session
        activate Database

        Database-->MeetingSessionRepository: Meeting Session updated
        deactivate Database

        MeetingSessionRepository-->MeetingService: Meeting Session started
        deactivate MeetingSessionRepository

        MeetingService->MeetingService: Keep parent Meeting InProgress and\nOnline Meeting Room unchanged (BR-60, BR-92, BR-95)

        MeetingService-->MeetingController: Meeting Session started successfully
        deactivate MeetingService

        MeetingController-->MeetingPage: MSG51 - Meeting session started successfully
        deactivate MeetingController

        MeetingPage-->Chair: MSG51 - Meeting session started successfully
    end
end

deactivate MeetingPage
