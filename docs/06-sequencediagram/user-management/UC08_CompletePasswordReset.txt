title UC-08 - Complete Password Reset

actor "User" as User
boundary "Reset Password Page" as ResetPage
control ":Auth Controller" as AuthController
control ":User Service" as UserService
participant ":Password Reset Token Store" as ResetTokenStore
participant ":User Repository" as UserRepository
control ":Token Service" as TokenService
control ":Audit Service" as AuditService
database ":Database" as Database

note over User, ResetPage: EX-6: a page opened without a reset code shows\nMSG129 - No password reset code was found.\nPlease open the link in the email again.\nIt sends no request, so it is not part of this execution.

User->ResetPage: Submit new password
activate ResetPage

ResetPage->AuthController: Reset password with the link
activate AuthController

AuthController->UserService: resetPassword(resetCode, newPassword)
activate UserService

UserService->ResetTokenStore: Look up the reset link (BR-20)
activate ResetTokenStore

ResetTokenStore-->UserService: Account the link belongs to
deactivate ResetTokenStore

alt Link is unknown, expired, used or replaced - EX-4
    UserService-->AuthController: MSG93 - The password reset link is invalid\nor has expired. Please contact an administrator.
    deactivate UserService

    AuthController-->ResetPage: Return failure
    deactivate AuthController

    ResetPage-->User: MSG93 - The password reset link is invalid\nor has expired. Please contact an administrator.

else Link is valid
    UserService->UserService: Validate the new password\n(same password rule as UC-05)

    alt New password is invalid - EX-5
        note over UserService, ResetTokenStore: The link is not used up;\nthe user may correct the password and resubmit

        UserService-->AuthController: MSG94 - Invalid new password
        deactivate UserService

        AuthController-->ResetPage: Return failure with the field error
        deactivate AuthController

        ResetPage-->User: MSG94 - Invalid new password

    else New password is valid
        UserService->ResetTokenStore: Use up the link (BR-20)
        activate ResetTokenStore

        ResetTokenStore-->UserService: Link used
        deactivate ResetTokenStore

        note over UserService, ResetTokenStore: If a simultaneous submission used the link first,\nthis one ends with MSG93 (EX-4)

        UserService->UserRepository: Get user account
        activate UserRepository

        UserRepository->Database: Retrieve user account
        activate Database

        Database-->UserRepository: User account
        deactivate Database

        UserRepository-->UserService: User account
        deactivate UserRepository

        UserService->UserService: Check eligibility: account is active\nand signs in with a password (BR-03, BR-22)

        alt Account is deactivated or has no password - EX-4
            UserService-->AuthController: MSG93 - The password reset link is invalid\nor has expired. Please contact an administrator.
            deactivate UserService

            AuthController-->ResetPage: Return failure
            deactivate AuthController

            ResetPage-->User: MSG93 - The password reset link is invalid\nor has expired. Please contact an administrator.

        else Account is eligible
            UserService->TokenService: End every session of the account (BR-20)
            activate TokenService

            TokenService-->UserService: Sessions ended
            deactivate TokenService

            UserService->UserRepository: Save the new password hash (BR-01)
            activate UserRepository

            UserRepository->Database: Update user password
            activate Database

            Database-->UserRepository: Password updated
            deactivate Database

            UserRepository-->UserService: User account updated
            deactivate UserRepository

            UserService->AuditService: Record completed password reset\n(actor: account owner) (BR-16)
            activate AuditService

            AuditService->Database: Store audit record
            activate Database

            Database-->AuditService: Audit record stored
            deactivate Database

            AuditService-->UserService: Password reset recorded
            deactivate AuditService

            UserService-->AuthController: Password reset completed
            deactivate UserService

            AuthController-->ResetPage: MSG92 - Password reset successfully.\nPlease sign in with your new password.
            deactivate AuthController

            opt This browser is still signed in - AF-1
                ResetPage->AuthController: Sign out this browser's session
                activate AuthController

                AuthController-->ResetPage: Sign-out result
                deactivate AuthController
            end

            ResetPage-->User: MSG92 - Password reset successfully.\nPlease sign in with your new password.

            opt Sign-out cannot be completed - AF-1
                ResetPage-->User: MSG06 - Unable to sign out. Please try again.
            end

            ResetPage-->User: Go to the sign-in page
        end
    end
end

deactivate ResetPage
