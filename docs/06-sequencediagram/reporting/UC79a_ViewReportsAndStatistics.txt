title UC-79a - View Reports & Statistics

actor "Internal User" as Actor
boundary "Reports Page" as ReportsPage
control ":Report Controller" as ReportController
control ":Report Service" as ReportService
participant ":Meeting Repository" as MeetingRepository
participant ":Report Fact Query" as ReportFactQuery
database ":Database" as Database

Actor->ReportsPage: View the manager figures and query a table with chosen parameters
activate ReportsPage

ReportsPage->ReportController: Get meeting statistics and the queried table
activate ReportController

ReportController->ReportService: getMeetingStatistics(actorId, fromMonth, toMonth)
activate ReportService


alt The period is not valid - EX-1
    ReportService-->ReportController: MSG463 - The report period is invalid. Choose up to 24 months, with the start month not after the end month.
    ReportController-->ReportsPage: MSG463 - The report period is invalid. Choose up to 24 months, with the start month not after the end month.
    ReportsPage-->Actor: MSG463 - The report period is invalid. Choose up to 24 months, with the start month not after the end month.

else The period is valid

    alt The query parameter is not valid - EX-2
        ReportService-->ReportController: MSG484 - The report parameters are invalid. Choose the data, grouping or filter again.
        ReportController-->ReportsPage: MSG484 - The report parameters are invalid. Choose the data, grouping or filter again.
        ReportsPage-->Actor: MSG484 - The report parameters are invalid. Choose the data, grouping or filter again.

    else Query parameters valid
        ReportService->MeetingRepository: Count the Meetings the actor may read whose planned start is in the period, per month, status and sensitivity (BR-149, BR-150)
        activate MeetingRepository

        MeetingRepository->Database: Retrieve counts of readable Meetings
        activate Database

        Database-->MeetingRepository: Counts
        deactivate Database

        MeetingRepository-->ReportService: Counts
        deactivate MeetingRepository

        ReportService->MeetingRepository: Get attendance, actual start and end times, and first minutes issue of the readable Ended Meetings in the period
        activate MeetingRepository

        MeetingRepository->Database: Retrieve attendance marks, actual start and end times, and minutes issue times
        activate Database

        Database-->MeetingRepository: Attendance marks, actual times, issue times
        deactivate Database

        MeetingRepository-->ReportService: Attendance marks, actual times, issue times
        deactivate MeetingRepository


        ReportService->ReportFactQuery: Read the rows of the chosen table for readable Meetings only, keeping draft votes and unissued minutes to current Chairs and Secretaries, recordings to current participants, and no combined hours (BR-153, BR-151)
        activate ReportFactQuery

        ReportFactQuery->Database: Retrieve readable rows of the chosen table
        activate Database

        Database-->ReportFactQuery: Rows
        deactivate Database

        ReportFactQuery-->ReportService: Rows
        deactivate ReportFactQuery

        ReportService-->ReportController: Manager figures (counts, rates and averages only - BR-152) and the queried table with its Total row
        ReportController-->ReportsPage: Manager figures and the queried table

        alt No readable Meeting in the period - AF-2
            ReportsPage-->Actor: MSG466 - There are no meetings you can view in this period.
        else At least one readable Meeting
            ReportsPage-->Actor: Manager figures on top, then the queried table with the chosen grouping and filters and its Total row
        end
    end
end

deactivate ReportService
deactivate ReportController
deactivate ReportsPage
