title UC-70a - View Reports & Statistics

actor "Internal User" as Actor
boundary "Reports Page" as ReportsPage
control ":Report Controller" as ReportController
control ":Report Service" as ReportService
participant ":Meeting Repository" as MeetingRepository
database ":Database" as Database

Actor->ReportsPage: View the report for the chosen period (BR-433)
activate ReportsPage
ReportsPage->ReportController: Get meeting statistics for the period
activate ReportController
ReportController->ReportService: getMeetingStatistics(actorId, fromMonth, toMonth)
activate ReportService
ReportService->ReportService: Check the start month is not after the end month\nand the period covers at most 24 months (BR-433)

alt The period is not valid - EX-1
    ReportService-->ReportController: MSG463 - The report period is invalid. Choose up to 24 months, with the start month not after the end month.
    ReportController-->ReportsPage: MSG463 - The report period is invalid. Choose up to 24 months, with the start month not after the end month.
    ReportsPage-->Actor: MSG463 - The report period is invalid. Choose up to 24 months, with the start month not after the end month.
else The period is valid
    ReportService->MeetingRepository: Count the Meetings the actor may read whose planned start is in the period,\nper month, status and sensitivity (BR-432, BR-434)
    activate MeetingRepository
    MeetingRepository->Database: Retrieve counts of readable Meetings
    activate Database
    Database-->MeetingRepository: Counts / Read failure
    deactivate Database
    MeetingRepository-->ReportService: Counts / Read failure
    deactivate MeetingRepository

    alt The data cannot be read - EX-2
        ReportService-->ReportController: MSG464 - Unable to load the report. Please try again.
        ReportController-->ReportsPage: MSG464 - Unable to load the report. Please try again.
        ReportsPage-->Actor: MSG464 - Unable to load the report. Please try again.
    else Counts read
        ReportService->MeetingRepository: Get attendance and first minutes issue of the readable Ended Meetings in the period
        activate MeetingRepository
        MeetingRepository->Database: Retrieve attendance marks and minutes issue times
        activate Database
        Database-->MeetingRepository: Attendance marks, issue times
        deactivate Database
        MeetingRepository-->ReportService: Attendance marks, issue times
        deactivate MeetingRepository
        ReportService->ReportService: Compute the average attendance rate (BR-435)\nand the average minutes turnaround (BR-436)
        ReportService-->ReportController: Meeting statistics (counts, rates and averages only - BR-437)
        ReportController-->ReportsPage: Meeting statistics

        alt No readable Meeting in the period - AF-2
            ReportsPage-->Actor: MSG466 - There are no meetings you can view in this period.
        else At least one readable Meeting
            ReportsPage-->Actor: Meetings per month, by status and by sensitivity,\naverage attendance rate and average minutes turnaround
        end
    end
end
deactivate ReportService
deactivate ReportController
deactivate ReportsPage
