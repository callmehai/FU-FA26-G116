title UC-86d - Delete Collected Voice Sample

actor "VoiceCollector" as Collector
boundary "Users Page" as UsersPage
control ":Voice Collection Controller" as CollectionController
control ":Voice Collection Service" as CollectionService
participant ":Voice ID Repository" as VoiceRepository
participant ":Audit Service" as AuditService
database ":Database" as Database

Collector->UsersPage: Confirm Delete on a sample collected for the person
activate UsersPage

UsersPage->CollectionController: Delete the collected voice sample
activate CollectionController

CollectionController->CollectionService: delete(userId, actorId, sampleId)
activate CollectionService

alt No access: no Voice sample collection permission, or the sample was recorded by the person - EX-1
    CollectionService-->CollectionController: Not found
    deactivate CollectionService

    CollectionController-->UsersPage: Return failure
    deactivate CollectionController

    UsersPage-->Collector: Show the sample as not found
else Collected sample exists
    CollectionService->VoiceRepository: Delete the sample with its protected voiceprint and recording (BR-452)
    activate VoiceRepository
    VoiceRepository->Database: Delete voice sample
    activate Database
    Database-->VoiceRepository: Sample deleted / Save failed
    deactivate Database
    VoiceRepository-->CollectionService: Sample deleted / Save failed
    deactivate VoiceRepository

    CollectionService->AuditService: Record the deleted collected sample (BR-453)
    activate AuditService
    AuditService-->CollectionService: Entry saved
    deactivate AuditService

    alt Sample cannot be deleted - EX-2
        CollectionService-->CollectionController: MSG315 - Unable to save changes. Please try again.
        deactivate CollectionService

        CollectionController-->UsersPage: MSG315 - Unable to save changes. Please try again.
        deactivate CollectionController

        UsersPage-->Collector: MSG315 - Unable to save changes. Please try again.
    else Sample deleted
        CollectionService->CollectionService: ref UC-86b - Record again is delete then record (AF-1)
        CollectionService-->CollectionController: MSG474 - Voice sample deleted.
        deactivate CollectionService

        CollectionController-->UsersPage: MSG474 - Voice sample deleted.
        deactivate CollectionController

        UsersPage-->Collector: MSG474 - Voice sample deleted.
    end
end

deactivate UsersPage
