title UC-72a - Create Folder

actor "Internal User" as Actor
boundary "Personal Library Screen" as LibraryScreen
control ":Folder Controller" as FolderController
control ":Folder Service" as FolderService
participant ":Folder Repository" as FolderRepository
database ":Database" as Database

Actor->LibraryScreen: Submit the new folder name at the library root or under an owned parent folder
activate LibraryScreen

LibraryScreen->FolderController: Create folder with name and optional parent folder
activate FolderController

FolderController->FolderService: createFolder(ownerId, parentId, name)
activate FolderService

opt A parent folder is selected
    FolderService->FolderRepository: Get the parent folder owned by the user (BR-219, BR-242)
    activate FolderRepository
    FolderRepository->Database: Retrieve the parent folder and its ancestors
    activate Database
    Database-->FolderRepository: Parent folder and ancestors / Not found
    deactivate Database
    FolderRepository-->FolderService: Parent folder and its depth / Not found
    deactivate FolderRepository
end

alt Parent folder is missing or not owned by the user - EX-2
    FolderService-->FolderController: MSG179 - The selected destination folder is not available in your personal library.
    FolderController-->LibraryScreen: MSG179 - The selected destination folder is not available in your personal library.
    LibraryScreen-->Actor: MSG179 - The selected destination folder is not available in your personal library.

else Parent folder is available or the library root is selected
    FolderService->FolderService: Check the folder name is not blank (BR-220)

    alt Folder name is blank - EX-1
        FolderService-->FolderController: MSG188 - Enter a folder name.
        FolderController-->LibraryScreen: MSG188 - Enter a folder name.
        LibraryScreen-->Actor: MSG188 - Enter a folder name.

    else Folder name exceeds 400 characters - EX-5
        FolderService-->FolderController: MSG348 - The text is longer than allowed.
        FolderController-->LibraryScreen: MSG348 - The text is longer than allowed.
        LibraryScreen-->Actor: MSG348 - The text is longer than allowed.

    else Folder name is valid
        FolderService->FolderService: Check the new folder would be at most level five (BR-191)

        alt New folder would be deeper than level five - EX-3
            FolderService-->FolderController: MSG189 - Folders cannot be nested more than five levels deep.
            FolderController-->LibraryScreen: MSG189 - Folders cannot be nested more than five levels deep.
            LibraryScreen-->Actor: MSG189 - Folders cannot be nested more than five levels deep.

        else Depth is within the limit
            FolderService->FolderRepository: Create the owned folder at that location,\nduplicate names permitted (BR-221)
            activate FolderRepository
            FolderRepository->Database: Insert folder
            activate Database
            Database-->FolderRepository: Saved / Failed
            deactivate Database
            FolderRepository-->FolderService: Created folder / Failed
            deactivate FolderRepository

            alt Folder cannot be created - EX-4
                FolderService-->FolderController: MSG190 - Unable to create the folder. No folder was created.
                FolderController-->LibraryScreen: MSG190 - Unable to create the folder. No folder was created.
                LibraryScreen-->Actor: MSG190 - Unable to create the folder. No folder was created.

            else Folder is created
                FolderService-->FolderController: Created folder
                FolderController-->LibraryScreen: Created folder
                LibraryScreen->LibraryScreen: Refresh the folder list
                LibraryScreen-->Actor: MSG187 - Folder created successfully.
            end
        end
    end
end

deactivate FolderService
deactivate FolderController
deactivate LibraryScreen
