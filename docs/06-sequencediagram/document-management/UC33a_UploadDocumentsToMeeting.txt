title UC-33a - Upload Documents to Meeting (AF-1)

actor "Chair or Secretary" as Actor
boundary "Meeting Documents Tab" as DocumentsTab
control ":Meeting Document Controller" as DocumentController
control ":Meeting Document Service" as DocumentService
participant ":Meeting Access Policy" as MeetingAccessPolicy
participant ":Meeting Document Repository" as MeetingDocumentRepository
participant ":Object Storage (R2)" as FileStorage
database ":Database" as Database

Actor->DocumentsTab: Submit the selected files, each PDF with its page count
activate DocumentsTab

DocumentsTab->DocumentController: Upload files to the Meeting
activate DocumentController

DocumentController->DocumentService: uploadDocuments(meetingId, files, pageCounts, actor)
activate DocumentService

DocumentService->MeetingAccessPolicy: Check actor can currently view the Meeting\nand is its current Chair or Secretary (BR-184, BR-195)
activate MeetingAccessPolicy
MeetingAccessPolicy->Database: Retrieve Meeting status and the actor's current Meeting role
activate Database
Database-->MeetingAccessPolicy: Meeting status and Meeting role / Not found
deactivate Database
MeetingAccessPolicy-->DocumentService: Access, Meeting role and Meeting status / No access
deactivate MeetingAccessPolicy

alt Meeting is unavailable or the actor can no longer view it - EX-7
    DocumentService-->DocumentController: MSG174 - This Meeting is not accessible.
    DocumentController-->DocumentsTab: MSG174 - This Meeting is not accessible.
    DocumentsTab-->Actor: MSG174 - This Meeting is not accessible.

else Actor is no longer the Chair or Secretary - EX-1
    DocumentService-->DocumentController: MSG162 - You no longer have permission to add documents to this Meeting.
    DocumentController-->DocumentsTab: MSG162 - You no longer have permission to add documents to this Meeting.
    DocumentsTab-->Actor: MSG162 - You no longer have permission to add documents to this Meeting.

else Meeting has ended - EX-6
    DocumentService-->DocumentController: MSG172 - Documents cannot be added after the Meeting has ended.
    DocumentController-->DocumentsTab: MSG172 - Documents cannot be added after the Meeting has ended.
    DocumentsTab-->Actor: MSG172 - Documents cannot be added after the Meeting has ended.

else Actor may add documents
    DocumentController->DocumentController: Check the declared request size before reading the submission\n(EX-8, BR-319)

    alt Declared request is larger than 201 MB - EX-8
        DocumentController-->DocumentsTab: MSG288 - Upload up to 10 files at a time, no larger than 200 MB in total.
        DocumentsTab-->Actor: MSG288 - Upload up to 10 files at a time, no larger than 200 MB in total.

    else Declared request is within the limit
        DocumentService->DocumentService: Read the submission and check it is a well-formed request with at least one file,\nat most 10 files totalling at most 200 MB, and that every file has a usable name,\na .pdf or .docx extension matching its content and at most 50 MB\n(BR-187, BR-214, BR-215, BR-319)

        alt Submission or any file is invalid - EX-3, EX-8
            DocumentService-->DocumentController: MSG164 / MSG288 - the matching message
            DocumentController-->DocumentsTab: MSG164 / MSG288 - the matching message
            DocumentsTab-->Actor: MSG164 / MSG288 - the matching message

        else Every file is valid
            DocumentService->MeetingDocumentRepository: Record one stored-file entry per file, before any byte is stored (ADR-0024)
            activate MeetingDocumentRepository
            MeetingDocumentRepository->Database: Insert the stored-file entries
            activate Database
            Database-->MeetingDocumentRepository: Recorded / Failed
            deactivate Database
            MeetingDocumentRepository-->DocumentService: Recorded / Failed
            deactivate MeetingDocumentRepository

            alt Stored-file entries cannot be recorded - EX-5
                DocumentService-->DocumentController: MSG166 - Unable to add the documents. No documents were added. Please try again.
                DocumentController-->DocumentsTab: MSG166 - Unable to add the documents. No documents were added. Please try again.
                DocumentsTab-->Actor: MSG166 - Unable to add the documents. No documents were added. Please try again.

            else Stored-file entries recorded
                DocumentService->FileStorage: Store each file unchanged under its stored-file entry (BR-183, BR-216)
                activate FileStorage
                FileStorage-->DocumentService: All files stored / Storing failed
                deactivate FileStorage

                alt Files cannot be stored - EX-5
                    DocumentService->FileStorage: Delete the files already stored in this submission (BR-286)
                    activate FileStorage
                    FileStorage-->DocumentService: Files deleted
                    deactivate FileStorage
                    DocumentService-->DocumentController: MSG166 - Unable to add the documents. No documents were added. Please try again.
                    DocumentController-->DocumentsTab: MSG166 - Unable to add the documents. No documents were added. Please try again.
                    DocumentsTab-->Actor: MSG166 - Unable to add the documents. No documents were added. Please try again.

                else All files stored
                    DocumentService->MeetingDocumentRepository: Save the library documents in the actor's Meeting folder\nand the general Meeting documents, in one transaction with the Meeting locked\n(BR-194, BR-210, BR-229, BR-286)
                    activate MeetingDocumentRepository
                    MeetingDocumentRepository->Database: Under the Meeting lock, recheck status and the actor's role,\nthen use the folder linked to this Meeting or create it at the library root named\n"<Meeting title> - dd/mm/yyyy" in Vietnam time (BR-192, BR-226, BR-228),\nand insert the library documents and the general Meeting documents\npointing at the stored-file entries (BR-227)
                    activate Database
                    Database-->MeetingDocumentRepository: Saved / Failed
                    deactivate Database
                    MeetingDocumentRepository-->DocumentService: Saved / Failed
                    deactivate MeetingDocumentRepository

                    alt Save fails: EX-7, EX-1, EX-6 or EX-5
                        DocumentService->FileStorage: Delete the files stored in this submission (BR-286)
                        activate FileStorage
                        FileStorage-->DocumentService: Files deleted
                        deactivate FileStorage
                        DocumentService-->DocumentController: MSG174 / MSG162 / MSG172 / MSG166 - the message of the failed check
                        DocumentController-->DocumentsTab: MSG174 / MSG162 / MSG172 / MSG166
                        DocumentsTab-->Actor: MSG174 / MSG162 / MSG172 / MSG166

                    else Documents added
                        DocumentService-->DocumentController: Number of documents added
                        DocumentController-->DocumentsTab: Number of documents added
                        DocumentController->DocumentController: Tell everyone in the Meeting that the document list has changed\n(at most 2 seconds, no reply awaited)
                        DocumentsTab->DocumentsTab: Refresh the Meeting document list
                        DocumentsTab-->Actor: MSG161 - Documents added to the Meeting successfully.
                    end
                end
            end
        end
    end
end

deactivate DocumentService
deactivate DocumentController
deactivate DocumentsTab
