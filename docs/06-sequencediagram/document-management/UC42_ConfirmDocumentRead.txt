title UC-42 - Confirm Document Read

actor "Chair / Secretary / Participant / Guest" as User
boundary "Document Viewer" as DocumentViewer
control ":Document Controller" as DocumentController
control ":Document Read Service" as ReadService
participant ":Meeting Access Policy" as MeetingAccessPolicy
participant ":Meeting Document Repository" as MeetingDocumentRepository
participant ":Document Read Confirmation Repository" as ReadConfirmationRepository
database ":Database" as Database

User->DocumentViewer: Click confirm read
activate DocumentViewer

alt Last page not reached - EX-1
    DocumentViewer-->User: MSG254 - Scroll to the last page before confirming.
else Last page reached
    DocumentViewer->DocumentController: Confirm document read
    activate DocumentController

    DocumentController->ReadService: confirmDocumentRead(meetingId, meetingDocumentId, actorId)
    activate ReadService

    ReadService->MeetingAccessPolicy: Check the actor can view the Meeting
    activate MeetingAccessPolicy
    MeetingAccessPolicy->Database: Check the actor's relationship to the Meeting
    activate Database
    Database-->MeetingAccessPolicy: Access / No access
    deactivate Database
    MeetingAccessPolicy-->ReadService: Access / No access
    deactivate MeetingAccessPolicy

    ReadService->MeetingDocumentRepository: Get the Vote document
    activate MeetingDocumentRepository
    MeetingDocumentRepository->Database: Retrieve the document linked to a Vote
    activate Database
    Database-->MeetingDocumentRepository: Vote document / Not available
    deactivate Database
    MeetingDocumentRepository-->ReadService: Vote document / Not available
    deactivate MeetingDocumentRepository

    alt Document or Meeting is no longer accessible - EX-2
        ReadService-->DocumentController: MSG156 - Meeting documents are not accessible.
        DocumentController-->DocumentViewer: MSG156 - Meeting documents are not accessible.
        DocumentViewer-->User: MSG156 - Meeting documents are not accessible.
    else Vote document is accessible
        ReadService->ReadConfirmationRepository: Check the actor is an eligible voter of an Open Vote
        activate ReadConfirmationRepository
        ReadConfirmationRepository->Database: Check eligible voter and Open Vote
        activate Database
        Database-->ReadConfirmationRepository: Eligible / Not eligible
        deactivate Database
        ReadConfirmationRepository-->ReadService: Eligible / Not eligible
        deactivate ReadConfirmationRepository

        alt Actor is not an eligible voter - EX-3
            ReadService-->DocumentController: MSG224 - You are not eligible to cast a ballot in this vote.
            DocumentController-->DocumentViewer: MSG224 - You are not eligible to cast a ballot in this vote.
            DocumentViewer-->User: MSG224 - You are not eligible to cast a ballot in this vote.
        else No Open Vote remains - EX-3
            ReadService-->DocumentController: MSG225 - This vote is no longer accepting ballots.
            DocumentController-->DocumentViewer: MSG225 - This vote is no longer accepting ballots.
            DocumentViewer-->User: MSG225 - This vote is no longer accepting ballots.
        else Eligible voter of an Open Vote
            ReadService->ReadConfirmationRepository: Save the confirmation (kept if already confirmed - AF-1)
            activate ReadConfirmationRepository
            ReadConfirmationRepository->Database: Insert the confirmation
            activate Database
            Database-->ReadConfirmationRepository: Saved
            deactivate Database
            ReadConfirmationRepository-->ReadService: Saved
            deactivate ReadConfirmationRepository

            ReadService-->DocumentController: MSG253 - Document read confirmed.
            DocumentController-->DocumentViewer: MSG253 - Document read confirmed.
            DocumentViewer-->User: MSG253 - Document read confirmed.
        end
    end

    deactivate ReadService
    deactivate DocumentController
end

deactivate DocumentViewer
