title UC-32a - View Meeting Documents

actor "Authorized User" as User
boundary "Meeting Documents Tab / Room Documents Panel" as DocumentsTab
control ":Meeting Document Controller" as DocumentController
control ":Meeting Document Service" as DocumentService
participant ":Meeting Access Policy" as MeetingAccessPolicy
participant ":Meeting Document Repository" as MeetingDocumentRepository
database ":Database" as Database

User->DocumentsTab: Open Meeting documents
activate DocumentsTab

DocumentsTab->DocumentController: View Meeting documents
activate DocumentController

DocumentController->DocumentService: getMeetingDocuments(meetingId, actor)
activate DocumentService

DocumentService->MeetingAccessPolicy: Check actor can currently view the Meeting (BR-275)
activate MeetingAccessPolicy
MeetingAccessPolicy->Database: Check the actor's current Meeting relationship
activate Database
Database-->MeetingAccessPolicy: Access / No access
deactivate Database
MeetingAccessPolicy-->DocumentService: Access / No access
deactivate MeetingAccessPolicy

alt Meeting documents are not accessible - EX-1
    DocumentService-->DocumentController: MSG156 - Meeting documents are not accessible.
    DocumentController-->DocumentsTab: MSG156 - Meeting documents are not accessible.
    DocumentsTab-->User: MSG156 - Meeting documents are not accessible.

else Actor can view the Meeting
    DocumentService->MeetingDocumentRepository: Get the current Meeting documents with their Agenda Item links,\npage count, adder, addition time and comment count, together with every Agenda Item\nincluding those that have no document (BR-211, BR-277)
    activate MeetingDocumentRepository
    MeetingDocumentRepository->Database: Retrieve documents not removed from the Meeting,\nand the Meeting agenda with the current Agenda Item
    activate Database
    Database-->MeetingDocumentRepository: Meeting documents and agenda / Load failed
    deactivate Database
    MeetingDocumentRepository-->DocumentService: Meeting documents and agenda / Load failed
    deactivate MeetingDocumentRepository

    alt Document list cannot be loaded - EX-2
        DocumentService-->DocumentController: MSG157 - Unable to load the document list. Please try again.
        DocumentController-->DocumentsTab: MSG157 - Unable to load the document list. Please try again.
        DocumentsTab-->User: MSG157 - Unable to load the document list. Please try again.

    else Documents loaded
        DocumentService->DocumentService: Group by Agenda Item in agenda order and put documents\nwith no Item link in the general group (BR-277, BR-280)

        DocumentService-->DocumentController: Grouped Meeting documents and the current Agenda Item
        DocumentController-->DocumentsTab: Grouped Meeting documents and the current Agenda Item

        opt Opened from the online meeting room - AF-3
            DocumentsTab->DocumentsTab: Place the current Agenda Item first, keep the server order of the other Items\nand offer reading only (BR-316)
        end

        alt No documents in the current grouping - AF-2
            DocumentsTab-->User: Show that no documents are available for the current grouping
        else Documents available
            DocumentsTab-->User: Show documents grouped by Agenda Item or general, with the files that can be added
        end

        DocumentsTab->DocumentsTab: Hide adding and linking once the Meeting has ended (BR-282)
        DocumentsTab->DocumentsTab: Read the list again when the system announces that the document list has changed
    end
end

deactivate DocumentService
deactivate DocumentController
deactivate DocumentsTab
