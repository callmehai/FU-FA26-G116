title UC-36c - Remove Document from Meeting

actor "Chair or Secretary" as Actor
boundary "Meeting Documents Tab" as DocumentsTab
control ":Meeting Document Controller" as DocumentController
control ":Meeting Document Service" as DocumentService
participant ":Meeting Access Policy" as MeetingAccessPolicy
participant ":Meeting Document Repository" as MeetingDocumentRepository
database ":Database" as Database

Actor->DocumentsTab: Confirm removing the document
activate DocumentsTab

DocumentsTab->DocumentController: Remove the document
activate DocumentController

DocumentController->DocumentService: removeDocument(meetingId, meetingDocumentId, actor)
activate DocumentService

DocumentService->MeetingAccessPolicy: Check the actor's Meeting role and the Meeting status
activate MeetingAccessPolicy
MeetingAccessPolicy->Database: Retrieve Meeting status and the actor's role
activate Database
Database-->MeetingAccessPolicy: Meeting status and role
deactivate Database
MeetingAccessPolicy-->DocumentService: Role and Meeting status
deactivate MeetingAccessPolicy

alt Actor is no longer the Chair or Secretary - EX-1
    DocumentService-->DocumentController: MSG169 - You no longer have permission to remove documents.
    DocumentController-->DocumentsTab: MSG169 - You no longer have permission to remove documents.
    DocumentsTab-->Actor: MSG169 - You no longer have permission to remove documents.
else Meeting no longer accepts changes - EX-3
    DocumentService-->DocumentController: MSG248 - Documents cannot be removed after the Meeting has ended.
    DocumentController-->DocumentsTab: MSG248 - Documents cannot be removed after the Meeting has ended.
    DocumentsTab-->Actor: MSG248 - Documents cannot be removed after the Meeting has ended.
else Actor may remove documents
    DocumentService->MeetingDocumentRepository: Get the document in the Meeting
    activate MeetingDocumentRepository
    MeetingDocumentRepository->Database: Retrieve the attached document
    activate Database
    Database-->MeetingDocumentRepository: Attached document / Not attached
    deactivate Database
    MeetingDocumentRepository-->DocumentService: Attached document / Not attached
    deactivate MeetingDocumentRepository

    alt Document is no longer attached - EX-2
        DocumentService-->DocumentController: MSG170 - This document is no longer attached to the Meeting.
        DocumentController-->DocumentsTab: MSG170 - This document is no longer attached to the Meeting.
        DocumentsTab-->Actor: MSG170 - This document is no longer attached to the Meeting.
    else Document is attached
        DocumentService->MeetingDocumentRepository: Remove the document and its Agenda Item links
        activate MeetingDocumentRepository
        MeetingDocumentRepository->Database: Mark the document removed and delete its links
        activate Database
        Database-->MeetingDocumentRepository: Saved
        deactivate Database
        MeetingDocumentRepository-->DocumentService: Saved
        deactivate MeetingDocumentRepository

        DocumentService-->DocumentController: Document removed
        DocumentController-->DocumentsTab: Document removed
        DocumentsTab-->Actor: MSG167 - Document removed from the Meeting.
    end
end

deactivate DocumentService
deactivate DocumentController
deactivate DocumentsTab
