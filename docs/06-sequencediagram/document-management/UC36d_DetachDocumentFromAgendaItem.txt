title UC-36d - Detach Document from Agenda Item

actor "Chair or Secretary" as Actor
boundary "Meeting Documents Tab" as DocumentsTab
control ":Meeting Document Controller" as DocumentController
control ":Meeting Document Service" as DocumentService
participant ":Meeting Access Policy" as MeetingAccessPolicy
participant ":Meeting Document Repository" as MeetingDocumentRepository
database ":Database" as Database

Actor->DocumentsTab: Confirm detaching the document
activate DocumentsTab

DocumentsTab->DocumentController: Detach the document from the Agenda Item
activate DocumentController

DocumentController->DocumentService: detachDocument(meetingId, agendaItemId, meetingDocumentId, actor)
activate DocumentService

DocumentService->MeetingAccessPolicy: Check the actor's Meeting role and the Meeting status
activate MeetingAccessPolicy
MeetingAccessPolicy->Database: Retrieve Meeting status and the actor's role
activate Database
Database-->MeetingAccessPolicy: Meeting status and role
deactivate Database
MeetingAccessPolicy-->DocumentService: Role and Meeting status
deactivate MeetingAccessPolicy

alt Actor is no longer the Chair or Secretary - EX-1
    DocumentService-->DocumentController: MSG241 - You no longer have permission to unlink documents.
    DocumentController-->DocumentsTab: MSG241 - You no longer have permission to unlink documents.
    DocumentsTab-->Actor: MSG241 - You no longer have permission to unlink documents.
else Meeting no longer accepts changes - EX-3
    DocumentService-->DocumentController: MSG247 - Document links cannot be changed after the Meeting has ended.
    DocumentController-->DocumentsTab: MSG247 - Document links cannot be changed after the Meeting has ended.
    DocumentsTab-->Actor: MSG247 - Document links cannot be changed after the Meeting has ended.
else Actor may unlink documents
    DocumentService->MeetingDocumentRepository: Get the document, the Agenda Item and their link
    activate MeetingDocumentRepository
    MeetingDocumentRepository->Database: Retrieve the document, the Agenda Item and the link
    activate Database
    Database-->MeetingDocumentRepository: Document, Agenda Item and link
    deactivate Database
    MeetingDocumentRepository-->DocumentService: Document, Agenda Item and link
    deactivate MeetingDocumentRepository

    alt Document, Agenda Item or link no longer exists - EX-2
        DocumentService-->DocumentController: MSG246 - This document is no longer linked to the Agenda Item.
        DocumentController-->DocumentsTab: MSG246 - This document is no longer linked to the Agenda Item.
        DocumentsTab-->Actor: MSG246 - This document is no longer linked to the Agenda Item.
    else Link exists
        DocumentService->MeetingDocumentRepository: Remove the link only
        activate MeetingDocumentRepository
        MeetingDocumentRepository->Database: Delete the link
        activate Database
        Database-->MeetingDocumentRepository: Saved
        deactivate Database
        MeetingDocumentRepository-->DocumentService: Saved
        deactivate MeetingDocumentRepository

        DocumentService-->DocumentController: Document detached
        DocumentController-->DocumentsTab: Document detached
        DocumentsTab-->Actor: MSG239 - Document detached from the Agenda Item.
    end
end

deactivate DocumentService
deactivate DocumentController
deactivate DocumentsTab
