title UC-12a - Update Role

actor "System Admin" as Admin
boundary "Role & Permission Management Page" as RolePage
control ":Role Controller" as RoleController
control ":Role Service" as RoleService
participant ":Role Repository" as RoleRepository
control ":Audit Service" as AuditService
database ":Database" as Database

Admin->RolePage: Submit updated role name and description
RolePage->RoleController: Update role
activate RoleController
RoleController->RoleService: Update role
activate RoleService
RoleService->RoleRepository: Get role by id
activate RoleRepository
RoleRepository->Database: Retrieve role
activate Database
Database-->RoleRepository: Role
RoleRepository-->RoleService: Role
alt Role not found
    RoleService-->RoleController: Role not found
    RoleController-->RolePage: Role not found
    RolePage-->Admin: Show error and refresh role list
else Role is a predefined role
    RoleService-->RoleController: Predefined role cannot be changed
    RoleController-->RolePage: MSG24 - Predefined role cannot be renamed or deleted
    RolePage-->Admin: Show error message
else Custom role
    RoleService->RoleService: Validate role information
    alt Invalid role information
        RoleService-->RoleController: Invalid role information
        RoleController-->RolePage: MSG20 - Invalid role information
        RolePage-->Admin: Show validation errors
    else No changes submitted
        RoleService-->RoleController: Nothing to update
        RoleController-->RolePage: MSG22 - Role updated successfully
        RolePage-->Admin: Show success message
    else Valid role information
        RoleService->RoleRepository: Check whether name is used by another role
        RoleRepository->Database: Find other role by name (case-insensitive)
        Database-->RoleRepository: Search result
        RoleRepository-->RoleService: Name used / available
        alt Role name already exists
            RoleService-->RoleController: Duplicate role name
            RoleController-->RolePage: MSG21 - Role name already exists
            RolePage-->Admin: Show duplicate name error
        else Role name is available
            RoleService->RoleRepository: Save updated role
            RoleRepository->Database: Update role name and description
            Database-->RoleRepository: Update result
            RoleRepository-->RoleService: Save result
            alt Role cannot be saved
                RoleService-->RoleController: Unable to update role
                RoleController-->RolePage: Error - Unable to update role
                RolePage-->Admin: Show error message
            else Role saved
                RoleService->AuditService: Record role update (before / after)
                activate AuditService
                AuditService->Database: Save audit log
                Database-->AuditService: Audit log saved
                AuditService-->RoleService: Audit recorded
                RoleService-->RoleController: Role updated successfully
                RoleController-->RolePage: MSG22 - Role updated successfully
                RolePage-->Admin: Show success message and updated role list
                deactivate AuditService
            end
        end
    end
end
deactivate Database
deactivate RoleRepository
deactivate RoleService
deactivate RoleController
