title UC-13 - View Audit Log

actor "System Admin" as Admin
boundary "Audit Log Page" as AuditLogPage
control ":Audit Log Controller" as AuditLogController
control ":Audit Log Query Service" as AuditLogQueryService
participant ":Audit Log Repository" as AuditLogRepository
database ":Database" as Database

Admin->AuditLogPage: View the audit log for the chosen period, filters and page
activate AuditLogPage
AuditLogPage->AuditLogController: Get the audit entries for the period, filters and page
activate AuditLogController
AuditLogController->AuditLogController: Check the caller's role still holds\nthe User administration permission (BR-440)

alt The permission is not held - EX-3
    AuditLogController-->AuditLogPage: Request refused, no audit entry returned
    AuditLogPage-->Admin: Audit Log is not shown
else The permission is held
    AuditLogController->AuditLogQueryService: getAuditEntries(criteria, page)
    activate AuditLogQueryService
    AuditLogQueryService->AuditLogQueryService: Check the start of the period is not after its end\nand every filter value is valid (BR-442)

    alt The period or a filter is not valid - EX-1
        AuditLogQueryService-->AuditLogController: MSG469 - The audit log filter is invalid. Check the period and the selected values.
        AuditLogController-->AuditLogPage: MSG469 - The audit log filter is invalid. Check the period and the selected values.
        AuditLogPage-->Admin: MSG469 - The audit log filter is invalid. Check the period and the selected values.
    else The criteria are valid
        AuditLogQueryService->AuditLogRepository: Find the entries matching all criteria,\nnewest first, one page (BR-11, BR-31, BR-442)
        activate AuditLogRepository
        AuditLogRepository->Database: Retrieve the matching audit entries and their total
        activate Database
        Database-->AuditLogRepository: Entries and total / Read failure
        deactivate Database
        AuditLogRepository-->AuditLogQueryService: Entries and total / Read failure
        deactivate AuditLogRepository

        alt The entries cannot be read - EX-2
            AuditLogQueryService-->AuditLogController: MSG470 - Unable to load the audit log. Please try again.
            AuditLogController-->AuditLogPage: MSG470 - Unable to load the audit log. Please try again.
            AuditLogPage-->Admin: MSG470 - Unable to load the audit log. Please try again.
        else Entries read
            AuditLogQueryService->AuditLogRepository: Get the user accounts and Guest invitations named by the entries
            activate AuditLogRepository
            AuditLogRepository->Database: Retrieve names and emails
            activate Database
            Database-->AuditLogRepository: Names and emails
            deactivate Database
            AuditLogRepository-->AuditLogQueryService: Names and emails
            deactivate AuditLogRepository
            AuditLogQueryService->AuditLogQueryService: Name each actor as a user account, a Guest\nor the system (BR-441)
            AuditLogQueryService-->AuditLogController: Page of entries with time, actor, event, object,\nIP address and recorded details (BR-441, BR-443)
            AuditLogController-->AuditLogPage: Page of audit entries

            alt No entry matches - AF-3
                AuditLogPage-->Admin: No matching audit entries (BR-12)
            else At least one entry matches
                AuditLogPage-->Admin: Audit entries, newest first, read-only
            end
        end
    end
    deactivate AuditLogQueryService
end
deactivate AuditLogController
deactivate AuditLogPage
