title UC-83 - Correct Issued Meeting Minutes

actor "Chair / Secretary" as Actor
boundary "Minutes Card (Biên bản tab)" as MinutesCard
control ":Minutes Controller" as MinutesController
control ":Minutes Service" as MinutesService
database ":Database" as Database

Actor->MinutesCard: Confirm Create Correction on an issued revision
activate MinutesCard
MinutesCard->MinutesController: correct(minutesId)
activate MinutesController
MinutesController->MinutesService: CorrectAsync(minutesId, actorId)
activate MinutesService
MinutesService->Database: Lock the Meeting and the revision, and retrieve both (FOR UPDATE)
activate Database
Database-->MinutesService: Meeting and revision / None
deactivate Database

alt Meeting not accessible, or actor is neither the current Chair nor the current Secretary\nand the selected revision is not Issued or Superseded - EX-5
    MinutesService-->MinutesController: Not found
    MinutesController-->MinutesCard: 404
    MinutesCard-->Actor: No minutes
else Actor may read the selected revision (Issued or Superseded) but is neither the current Chair nor the current Secretary - EX-1
    MinutesService-->MinutesController: MSG397 - Only the Chair or Secretary may write the minutes.
    MinutesController-->MinutesCard: 403 MSG397
    MinutesCard-->Actor: MSG397 - Only the Chair or Secretary may write the minutes.
else Actor is the current Chair or Secretary
    MinutesService->MinutesService: Check the selected revision is Issued, then that no later revision\nof these minutes is still unissued (BR-410)

    alt The selected revision is not Issued (Draft, WaitingApproval, Rejected or Superseded) - EX-2
        MinutesService-->MinutesController: MSG433 - Only issued minutes can be corrected.
        MinutesController-->MinutesCard: 409 MSG433
        MinutesCard-->Actor: MSG433 - Only issued minutes can be corrected.
    else The selected revision is Issued, but a later revision is still unissued - EX-3
        MinutesService-->MinutesController: MSG434 - A correction of these minutes is already in progress.
        MinutesController-->MinutesCard: 409 MSG434
        MinutesCard-->Actor: MSG434 - A correction of these minutes is already in progress.
    else Correction valid
        MinutesService->Database: Insert a Draft revision: the issued text, revision number + 1,\npointing at the issued revision (BR-409); the issued revision is not changed
        activate Database
        Database-->MinutesService: Saved / Failed / Unique violation
        deactivate Database

        alt Saved
            MinutesService-->MinutesController: New revision
            MinutesController-->MinutesCard: 201 MSG432 - Correction draft created.
            MinutesCard-->Actor: MSG432 - Correction draft created. The new revision opens for editing (UC-60)
        else Another correction was created at the same moment - unique violation on the revision number - EX-3
            MinutesService-->MinutesController: MSG434 - A correction of these minutes is already in progress.
            MinutesController-->MinutesCard: 409 MSG434
            MinutesCard-->Actor: MSG434 - A correction of these minutes is already in progress.
        else The revision cannot be saved - EX-4
            MinutesService-->MinutesController: MSG404 - Unable to save the minutes. Please try again.
            MinutesController-->MinutesCard: 503 MSG404
            MinutesCard-->Actor: MSG404 - Unable to save the minutes. Please try again.
        end
    end
end
deactivate MinutesService
deactivate MinutesController
deactivate MinutesCard
