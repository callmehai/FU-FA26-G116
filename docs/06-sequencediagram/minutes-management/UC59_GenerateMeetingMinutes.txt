title UC-59 - Generate Meeting Minutes

actor "Chair / Secretary" as Actor
boundary "Minutes Card (Biên bản tab)" as MinutesCard
control ":Minutes Controller" as MinutesController
control ":Minutes Service" as MinutesService
participant ":Meeting Repository" as MeetingRepository
participant ":Minutes Template" as MinutesTemplate
participant ":Summary Service" as SummaryService
database ":Database" as Database

Actor->MinutesCard: Select Create minutes, or Fill from meeting data
activate MinutesCard
MinutesCard->MinutesController: create(meetingId, rebuild)
activate MinutesController
MinutesController->MinutesService: createAsync(meetingId, actorId, rebuild)
activate MinutesService
MinutesService->MeetingRepository: Get the Meeting
activate MeetingRepository
MeetingRepository->Database: Retrieve Meeting
activate Database
Database-->MeetingRepository: Meeting / Not found
deactivate Database
MeetingRepository-->MinutesService: Meeting / Not found
deactivate MeetingRepository
MinutesService->MinutesService: Check the actor is the current Chair or Secretary (BR-386),\nthe Meeting is InProgress or Ended (BR-387), and the latest\nrevision is absent or still a draft (BR-388)

alt Actor is not the current Chair or Secretary - EX-1
    MinutesService-->MinutesController: MSG397 - Only the Chair or Secretary may write the minutes.
    MinutesController-->MinutesCard: MSG397 - Only the Chair or Secretary may write the minutes.
    MinutesCard-->Actor: MSG397 - Only the Chair or Secretary may write the minutes.
else The Meeting has not started or was cancelled - EX-2
    MinutesService-->MinutesController: MSG398 - The minutes can be written only while the meeting is in progress or after it has ended.
    MinutesController-->MinutesCard: MSG398 - The minutes can be written only while the meeting is in progress or after it has ended.
    MinutesCard-->Actor: MSG398 - The minutes can be written only while the meeting is in progress or after it has ended.
else The minutes can no longer be changed - EX-4
    MinutesService-->MinutesController: MSG400 - The minutes have been submitted or issued and can no longer be changed.
    MinutesController-->MinutesCard: MSG400 - The minutes have been submitted or issued and can no longer be changed.
    MinutesCard-->Actor: MSG400 - The minutes have been submitted or issued and can no longer be changed.
else A draft already exists and rebuild is false - EX-3
    MinutesService-->MinutesController: MSG399 - This meeting already has a minutes draft.
    MinutesController-->MinutesCard: MSG399 - This meeting already has a minutes draft.
    MinutesCard-->Actor: MSG399 - This meeting already has a minutes draft.
else Actor may build
    opt A draft already exists - AF-2
        MinutesCard-->Actor: Warn that every correction will be replaced (BR-388)
        Actor->MinutesCard: Confirm
    end
    MinutesService->Database: Retrieve participants, guests, attendance, agenda and closed votes
    activate Database
    Database-->MinutesService: Meeting records
    deactivate Database
    MinutesService->SummaryService: Read the current AI draft (reviewed or not)
    activate SummaryService
    SummaryService-->MinutesService: Sections I-III / None
    deactivate SummaryService
    MinutesService->MinutesTemplate: Build the fixed template (Mẫu 1.4 Nghị định 30) (BR-383, BR-384)
    activate MinutesTemplate
    alt An AI draft exists
        MinutesTemplate-->MinutesService: Minutes with sections I-III from the draft, marked reviewed or not
    else No AI draft - AF-3
        MinutesTemplate-->MinutesService: Minutes with the agenda and the Chair's conclusions, and "......" to fill (BR-382)
    end
    deactivate MinutesTemplate
    MinutesService->Database: Save the draft with its revision number
    activate Database
    Database-->MinutesService: Saved / Failed
    deactivate Database

    alt Saved - AF-1 when this is the first draft
        MinutesService-->MinutesController: State
        MinutesController-->MinutesCard: 201 MSG395 - Minutes draft created.
        MinutesCard-->Actor: MSG395 - Minutes draft created.
    else The draft cannot be saved - EX-5
        MinutesService-->MinutesController: MSG404 - Unable to save the minutes. Please try again.
        MinutesController-->MinutesCard: MSG404 - Unable to save the minutes. Please try again.
        MinutesCard-->Actor: MSG404 - Unable to save the minutes. Please try again.
    end
end
deactivate MinutesService
deactivate MinutesController
deactivate MinutesCard
