title UC-63 - Create / Configure Vote

actor "Chair or Secretary" as Actor
boundary "Meeting Management Page" as MeetingPage
control ":Vote Controller" as VoteController
control ":Vote Service" as VoteService
participant ":Meeting Access Policy" as MeetingAccessPolicy
participant ":Vote Repository" as VoteRepository
database ":Database" as Database

Actor->MeetingPage: Select Create Vote or Edit/Delete a Draft Vote
activate MeetingPage

MeetingPage->VoteController: Manage vote draft
activate VoteController
VoteController->VoteService: manageVoteDraft(meetingId, actorId, action, data)
activate VoteService

VoteService->MeetingAccessPolicy: Check actor can access the Meeting and Vote
activate MeetingAccessPolicy
MeetingAccessPolicy->Database: Check Meeting relationship or Guest invitation
activate Database
Database-->MeetingAccessPolicy: Access / No access
deactivate Database
MeetingAccessPolicy-->VoteService: Access / No access
deactivate MeetingAccessPolicy

alt Meeting or Vote is not accessible - EX-3
    VoteService-->VoteController: MSG205 - Meeting votes are not accessible.
    VoteController-->MeetingPage: MSG205 - Meeting votes are not accessible.
    MeetingPage-->Actor: MSG205 - Meeting votes are not accessible.
else Meeting and Vote are accessible
    alt Draft operation is no longer allowed - EX-2
        VoteService-->VoteController: MSG213 - Only Draft votes may be managed by the current Chair or Secretary while the meeting is Approved, Published or InProgress.
        VoteController-->MeetingPage: MSG213 - Only Draft votes may be managed by the current Chair or Secretary while the meeting is Approved, Published or InProgress.
        MeetingPage-->Actor: MSG213 - Only Draft votes may be managed by the current Chair or Secretary while the meeting is Approved, Published or InProgress.
    else Operation is allowed
        alt Invalid Vote information - EX-1
            VoteService-->VoteController: MSG209 - Invalid vote information. Check the highlighted fields.
            VoteController-->MeetingPage: MSG209 - Invalid vote information. Check the highlighted fields.
            MeetingPage-->Actor: MSG209 - Invalid vote information. Check the highlighted fields.
        else Information is valid
            VoteService->VoteRepository: Save, update or delete the Draft Vote
            activate VoteRepository
            VoteRepository->Database: Update Vote
            activate Database
            Database-->VoteRepository: Updated
            deactivate Database
            VoteRepository-->VoteService: Updated Vote
            deactivate VoteRepository

            VoteService-->VoteController: Success message
            VoteController-->MeetingPage: Success message
            MeetingPage-->Actor: Show saved Draft Vote
        end
    end
end

deactivate VoteService
deactivate VoteController
deactivate MeetingPage
