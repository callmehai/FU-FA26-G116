title UC-76a - Attach Documents to Vote

actor "Chair or Secretary" as Actor
boundary "Meeting Management Page" as MeetingPage
control ":Vote Controller" as VoteController
control ":Vote Service" as VoteService
participant ":Vote Repository" as VoteRepository
database ":Database" as Database

Actor->MeetingPage: Choose the paperclip on a Draft Vote
activate MeetingPage

MeetingPage->VoteController: Attach documents to vote
activate VoteController
VoteController->VoteService: attachDocuments(meetingId, voteId, actorId, documents)
activate VoteService

VoteService->VoteRepository: Verify Vote and documents
activate VoteRepository
VoteRepository->Database: Retrieve Vote and documents
activate Database
Database-->VoteRepository: Vote and documents
deactivate Database
VoteRepository-->VoteService: Vote and documents
deactivate VoteRepository

alt Vote documents can no longer be changed - EX-1
    VoteService-->VoteController: MSG213 - Only Draft votes may be managed by the current Chair or Secretary while the meeting is Approved, Published or InProgress.
    VoteController-->MeetingPage: MSG213 - Only Draft votes may be managed by the current Chair or Secretary while the meeting is Approved, Published or InProgress.
    MeetingPage-->Actor: MSG213 - Only Draft votes may be managed by the current Chair or Secretary while the meeting is Approved, Published or InProgress.
else Change is allowed
    alt Document is no longer in the Meeting - EX-2
        VoteService-->VoteController: MSG170 - This document is no longer attached to the Meeting. Refresh the document list.
        VoteController-->MeetingPage: MSG170 - This document is no longer attached to the Meeting. Refresh the document list.
        MeetingPage-->Actor: MSG170 - This document is no longer attached to the Meeting. Refresh the document list.
    else Document is still in the Meeting
        alt Document is already attached - EX-3
            VoteService-->VoteController: MSG266 - One or more selected documents are already attached to the vote.
            VoteController-->MeetingPage: MSG266 - One or more selected documents are already attached to the vote.
            MeetingPage-->Actor: MSG266 - One or more selected documents are already attached to the vote.
        else Document is not attached yet
            VoteService->VoteRepository: Attach documents to the Vote
            activate VoteRepository
            VoteRepository->Database: Insert Vote documents
            activate Database
            Database-->VoteRepository: Attached
            deactivate Database
            VoteRepository-->VoteService: Attached
            deactivate VoteRepository

            VoteService-->VoteController: MSG265 - Documents attached to the vote successfully.
            VoteController-->MeetingPage: MSG265 - Documents attached to the vote successfully.
            MeetingPage-->Actor: MSG265 - Documents attached to the vote successfully.
        end
    end
end

deactivate VoteService
deactivate VoteController
deactivate MeetingPage
