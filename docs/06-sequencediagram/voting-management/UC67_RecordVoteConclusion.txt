title UC-67 - Record Vote Conclusion

actor "Chair" as Actor
boundary "Meeting Management Page" as MeetingPage
control ":Vote Controller" as VoteController
control ":Vote Service" as VoteService
participant ":Vote Repository" as VoteRepository
database ":Database" as Database

Actor->MeetingPage: Open the result of a Closed Vote
activate MeetingPage

MeetingPage->VoteController: Record vote conclusion
activate VoteController
VoteController->VoteService: recordConclusion(meetingId, voteId, actorId, conclusion, note)
activate VoteService

VoteService->VoteRepository: Get Vote
activate VoteRepository
VoteRepository->Database: Retrieve Vote
activate Database
Database-->VoteRepository: Vote
deactivate Database
VoteRepository-->VoteService: Vote
deactivate VoteRepository

alt Conclusion is invalid - EX-1
    VoteService-->VoteController: MSG232 - Select Passed, NotPassed or Deferred.
    VoteController-->MeetingPage: MSG232 - Select Passed, NotPassed or Deferred.
    MeetingPage-->Actor: MSG232 - Select Passed, NotPassed or Deferred.
else Conclusion is valid
    alt Conclusion already recorded - EX-2
        VoteService-->VoteController: MSG233 - The vote conclusion has already been recorded and cannot be changed.
        VoteController-->MeetingPage: MSG233 - The vote conclusion has already been recorded and cannot be changed.
        MeetingPage-->Actor: MSG233 - The vote conclusion has already been recorded and cannot be changed.
    else No conclusion recorded yet
        alt Recording is no longer allowed - EX-3
            VoteService-->VoteController: MSG234 - Only the current Chair can record a conclusion for a Closed vote while the meeting is InProgress or Ended.
            VoteController-->MeetingPage: MSG234 - Only the current Chair can record a conclusion for a Closed vote while the meeting is InProgress or Ended.
            MeetingPage-->Actor: MSG234 - Only the current Chair can record a conclusion for a Closed vote while the meeting is InProgress or Ended.
        else Recording is allowed
            VoteService->VoteRepository: Record conclusion
            activate VoteRepository
            VoteRepository->Database: Update Vote conclusion
            activate Database
            Database-->VoteRepository: Updated
            deactivate Database
            VoteRepository-->VoteService: Updated Vote
            deactivate VoteRepository

            VoteService-->VoteController: MSG235 - Vote conclusion recorded successfully.
            VoteController-->MeetingPage: MSG235 - Vote conclusion recorded successfully.
            MeetingPage-->Actor: MSG235 - Vote conclusion recorded successfully.
        end
    end
end

deactivate VoteService
deactivate VoteController
deactivate MeetingPage
