title UC-53 - Create / Configure Vote

actor "Chair / Secretary" as Actor
boundary "Meeting Management Page" as MeetingPage
control ":Vote Controller" as VoteController
control ":Vote Service" as VoteService
participant ":Meeting Participant Repository" as ParticipantRepository
participant ":Vote Repository" as VoteRepository
database ":Database" as Database

Actor->MeetingPage: Save Vote draft / Confirm Delete Draft Vote / Open vote from the form
activate MeetingPage
MeetingPage->VoteController: Create, configure, delete or open Vote
activate VoteController
VoteController->VoteService: manageVoteDraft(meetingId, voteId, actorId, operation, voteInfo)
activate VoteService

VoteService->VoteRepository: Get Meeting and the selected Vote, if any, with current statuses
activate VoteRepository
VoteRepository->Database: Get Meeting and the selected Vote, if any, with current statuses
activate Database
Database-->VoteRepository: Meeting and Vote / Not found
deactivate Database
VoteRepository-->VoteService: Meeting and Vote / Not found
deactivate VoteRepository
VoteService->ParticipantRepository: Check current Chair or Secretary assignment
activate ParticipantRepository
ParticipantRepository->Database: Check current Chair or Secretary assignment
activate Database
Database-->ParticipantRepository: Current Chair or Secretary / Not eligible
deactivate Database
ParticipantRepository-->VoteService: Current Chair or Secretary / Not eligible
deactivate ParticipantRepository
alt Meeting or Vote not accessible - EX-6
    VoteService-->VoteController: MSG205 - Meeting votes are not accessible.
    VoteController-->MeetingPage: MSG205 - Meeting votes are not accessible.
    MeetingPage-->Actor: MSG205 - Meeting votes are not accessible.
else Actor not Chair or Secretary, Meeting not Approved, Published or InProgress, or existing Vote not Draft - EX-2
    VoteService-->VoteController: MSG213 - Only Draft votes may be managed by the current Chair or Secretary\nwhile the meeting is Approved, Published or InProgress.
    VoteController-->MeetingPage: MSG213 - Only Draft votes may be managed by the current Chair or Secretary\nwhile the meeting is Approved, Published or InProgress.
    MeetingPage-->Actor: MSG213 - Only Draft votes may be managed by the current Chair or Secretary\nwhile the meeting is Approved, Published or InProgress.
else Draft operation allowed (BR-189, BR-252, BR-254)
    alt Delete a Draft Vote - AF-2
        VoteService->VoteRepository: Recheck Vote is Draft and delete only this Draft Vote (BR-189)
        activate VoteRepository
        VoteRepository->Database: Delete the selected Draft Vote
        activate Database
        Database-->VoteRepository: Deleted / Delete failed; Draft unchanged
        deactivate Database
        VoteRepository-->VoteService: Deleted / Delete failed; Draft unchanged
        deactivate VoteRepository
        alt Draft cannot be deleted - EX-5
            VoteService-->VoteController: MSG216 - Unable to delete the vote draft. The draft remains unchanged. Please try again.
            VoteController-->MeetingPage: MSG216 - Unable to delete the vote draft. The draft remains unchanged. Please try again.
            MeetingPage-->Actor: MSG216 - Unable to delete the vote draft. The draft remains unchanged. Please try again.
        else Draft deleted
            VoteService-->VoteController: MSG212 - Vote draft deleted successfully.
            VoteController-->MeetingPage: MSG212 - Vote draft deleted successfully.
            MeetingPage-->Actor: MSG212 - Vote draft deleted successfully.
        end
    else Open vote from the form, current Chair only - AF-3
        ref over VoteController, VoteService: UC-54 - Open Vote (AF-1)
        end ref
    else Save draft
        VoteService->VoteService: Validate required content, at least two distinct non-empty options,\nballot type and at least one eligible role; no Agenda Item is requested\n(BR-255, BR-256, BR-257, BR-272, BR-285)
        alt Invalid Vote information - EX-1
            VoteService-->VoteController: MSG209 - Invalid vote information. Check the highlighted fields.
            VoteController-->MeetingPage: MSG209 - Invalid vote information. Check the highlighted fields.
            MeetingPage-->Actor: MSG209 - Invalid vote information. Check the highlighted fields.
        else Vote information is valid
            alt New Vote - Main Flow
                VoteService->VoteRepository: Create Draft Vote under the Meeting; eligible-voter list is not fixed (BR-190, BR-253, BR-285)
                activate VoteRepository
                VoteRepository->Database: Insert Draft Vote
                activate Database
                Database-->VoteRepository: Draft Vote created / Save failed
                deactivate Database
                VoteRepository-->VoteService: Draft Vote created / Save failed
                deactivate VoteRepository
                alt Draft cannot be created - EX-3
                    VoteService-->VoteController: MSG214 - Unable to create the vote draft. No draft was created. Please try again.
                    VoteController-->MeetingPage: MSG214 - Unable to create the vote draft. No draft was created. Please try again.
                    MeetingPage-->Actor: MSG214 - Unable to create the vote draft. No draft was created. Please try again.
                else Draft created
                    VoteService-->VoteController: MSG210 - Vote draft created successfully.
                    VoteController-->MeetingPage: MSG210 - Vote draft created successfully.
                    MeetingPage-->Actor: MSG210 - Vote draft created successfully.
                end
            else Existing Draft Vote - AF-1
                VoteService->VoteRepository: Recheck Vote is Draft and update the draft (BR-254)
                activate VoteRepository
                VoteRepository->Database: Update Draft Vote
                activate Database
                Database-->VoteRepository: Draft Vote updated / Save failed; draft unchanged
                deactivate Database
                VoteRepository-->VoteService: Draft Vote updated / Save failed; draft unchanged
                deactivate VoteRepository
                alt Draft cannot be updated - EX-4
                    VoteService-->VoteController: MSG215 - Unable to update the vote draft. The draft remains unchanged. Please try again.
                    VoteController-->MeetingPage: MSG215 - Unable to update the vote draft. The draft remains unchanged. Please try again.
                    MeetingPage-->Actor: MSG215 - Unable to update the vote draft. The draft remains unchanged. Please try again.
                else Draft updated
                    VoteService-->VoteController: MSG211 - Vote draft updated successfully.
                    VoteController-->MeetingPage: MSG211 - Vote draft updated successfully.
                    MeetingPage-->Actor: MSG211 - Vote draft updated successfully.
                end
            end
        end
    end
end

deactivate VoteService
deactivate VoteController
deactivate MeetingPage
