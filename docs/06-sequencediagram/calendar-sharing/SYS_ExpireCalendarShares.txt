title System - Expire Calendar Shares (BR-425)

actor "System" as System
control ":Calendar Share Expiry Job" as ExpiryJob
participant ":Calendar Share Repository" as ShareRepository
control ":Audit Service" as AuditService
control ":Notification Service" as NotificationService
database ":Database" as Database

System->ExpiryJob: Run daily at 00:00 Asia/Ho_Chi_Minh (pending PO Q4)
activate ExpiryJob

ExpiryJob->ShareRepository: Find Effective shares whose end date is before today (BR-425)
activate ShareRepository
ShareRepository->Database: Retrieve expiring shares
activate Database
Database-->ShareRepository: Expiring shares
deactivate Database
ShareRepository-->ExpiryJob: Expiring shares
deactivate ShareRepository

opt At least one Effective share expires
    loop Each expiring share (processed independently; one failure does not block the others)
        ExpiryJob->ShareRepository: Set status to Expired (BR-425)
        activate ShareRepository
        ShareRepository->Database: Update share status
        activate Database
        Database-->ShareRepository: Updated
        deactivate Database
        ShareRepository-->ExpiryJob: Expired
        deactivate ShareRepository

        ExpiryJob->AuditService: Record expiry (BR-426)
        activate AuditService
        AuditService->Database: Store audit record
        activate Database
        Database-->AuditService: Audit record created
        deactivate Database
        AuditService-->ExpiryJob: Recorded
        deactivate AuditService

        ExpiryJob->NotificationService: Notify both sides (BR-426, DeduplicationKey)
        activate NotificationService
        NotificationService->Database: Record notifications
        activate Database
        Database-->NotificationService: Notifications recorded
        deactivate Database
        NotificationService-->ExpiryJob: Notified
        deactivate NotificationService
    end
end

opt Pending shares past their end date (pending PO Q-B)
    ExpiryJob->ShareRepository: Find Pending shares whose end date is before today
    activate ShareRepository
    ShareRepository->Database: Retrieve pending expired shares
    activate Database
    Database-->ShareRepository: Pending expired shares
    deactivate Database
    ShareRepository-->ExpiryJob: Pending expired shares
    deactivate ShareRepository

    loop Each pending expired share (processed independently)
        ExpiryJob->ShareRepository: Set status to Expired (BR-425)
        activate ShareRepository
        ShareRepository->Database: Update share status
        activate Database
        Database-->ShareRepository: Saved
        deactivate Database
        ShareRepository-->ExpiryJob: Expired
        deactivate ShareRepository

        ExpiryJob->AuditService: Record expiry (BR-426)
        activate AuditService
        AuditService->Database: Store audit record
        activate Database
        Database-->AuditService: Saved
        deactivate Database
        AuditService-->ExpiryJob: Recorded
        deactivate AuditService

        ExpiryJob->NotificationService: Notify the sender (BR-426, DeduplicationKey)
        activate NotificationService
        NotificationService->Database: Record notification
        activate Database
        Database-->NotificationService: Saved
        deactivate Database
        NotificationService-->ExpiryJob: Notified
        deactivate NotificationService
    end
end

opt Pending changes past their deadline (pending PO Q-B)
    ExpiryJob->ShareRepository: Find pending changes whose deadline is before today
    activate ShareRepository
    ShareRepository->Database: Retrieve expired pending changes
    activate Database
    Database-->ShareRepository: Expired pending changes
    deactivate Database
    ShareRepository-->ExpiryJob: Expired pending changes
    deactivate ShareRepository

    loop Each expired pending change (processed independently)
        ExpiryJob->ShareRepository: Withdraw the change, leave the share as it was
        activate ShareRepository
        ShareRepository->Database: Close the pending change
        activate Database
        Database-->ShareRepository: Saved
        deactivate Database
        ShareRepository-->ExpiryJob: Change withdrawn
        deactivate ShareRepository

        ExpiryJob->AuditService: Record withdrawal (BR-426)
        activate AuditService
        AuditService->Database: Store audit record
        activate Database
        Database-->AuditService: Saved
        deactivate Database
        AuditService-->ExpiryJob: Recorded
        deactivate AuditService

        ExpiryJob->NotificationService: Notify both sides (BR-426, DeduplicationKey)
        activate NotificationService
        NotificationService->Database: Record notifications
        activate Database
        Database-->NotificationService: Saved
        deactivate Database
        NotificationService-->ExpiryJob: Notified
        deactivate NotificationService
    end
end

note right of ExpiryJob: Re-running the job does not send duplicate notifications (DeduplicationKey).\nPending shares past their end date close as Expired and notify the sender (pending PO Q-B).\nPending changes past their deadline withdraw themselves and leave the share as it was (pending PO Q-B).

ExpiryJob-->System: Run finished

deactivate ExpiryJob
