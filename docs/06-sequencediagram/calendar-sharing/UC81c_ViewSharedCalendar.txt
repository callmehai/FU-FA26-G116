title UC-81c - View Shared Calendar

actor "Member" as Actor
boundary "Calendar Sharing Page" as SharingPage
control ":Calendar Sharing Controller" as SharingController
control ":Calendar Sharing Service" as SharingService
participant ":Calendar Share Repository" as ShareRepository
participant ":Meeting Repository" as MeetingRepository
database ":Database" as Database

Actor->SharingPage: Open the Lịch được chia sẻ tab
activate SharingPage

SharingPage->SharingController: View shared calendar
activate SharingController
SharingController->SharingService: viewSharedCalendar(actorId, week)
activate SharingService

alt Actor cannot create meetings - EX-1
    SharingService-->SharingController: MSG448 - Only a Member can do this.
    SharingController-->SharingPage: MSG448 - Only a Member can do this.
    SharingPage-->Actor: MSG448 - Only a Member can do this.
else Actor is a Member
    SharingService->ShareRepository: Load Effective or Stopped shares
    activate ShareRepository
    ShareRepository->Database: Retrieve shares
    activate Database
    Database-->ShareRepository: Shares
    deactivate Database
    ShareRepository-->SharingService: Shares
    deactivate ShareRepository

    SharingService->MeetingRepository: Load sharers' meetings
    activate MeetingRepository
    MeetingRepository->Database: Retrieve meetings
    activate Database
    Database-->MeetingRepository: Meetings
    deactivate Database
    MeetingRepository-->SharingService: Meetings
    deactivate MeetingRepository

    SharingService-->SharingController: Week view
    SharingController-->SharingPage: Week view
    SharingPage-->Actor: Show week view with busy blocks
end

deactivate SharingService
deactivate SharingController
deactivate SharingPage
