title UC-81a - Find Meeting Time Slots

actor "Meeting Organizer" as Actor
boundary "Find Meeting Time Page" as FindPage
control ":Meeting Time Controller" as TimeController
control ":Meeting Time Service" as TimeService
participant ":Calendar Share Repository" as ShareRepository
participant ":Meeting Repository" as MeetingRepository
database ":Database" as Database

Actor->FindPage: Open the Tìm giờ họp page
activate FindPage

Actor->FindPage: Enter search parameters
FindPage->TimeController: Find meeting time slots
activate TimeController
TimeController->TimeService: findSlots(actorId, parameters)
activate TimeService

alt Search parameters are invalid - EX-1
    TimeService-->TimeController: MSG444 - The meeting-time search is invalid. Check the highlighted fields.
    TimeController-->FindPage: MSG444 - The meeting-time search is invalid. Check the highlighted fields.
    FindPage-->Actor: MSG444 - The meeting-time search is invalid. Check the highlighted fields.
else Parameters are valid
    alt Actor has no right to create meetings - EX-2
        TimeService-->TimeController: MSG448 - Only a Meeting Organizer can do this.
        TimeController-->FindPage: MSG448 - Only a Meeting Organizer can do this.
        FindPage-->Actor: MSG448 - Only a Meeting Organizer can do this.
    else Actor is a Meeting Organizer
        TimeService->ShareRepository: Load Effective shares of invitees
        activate ShareRepository
        ShareRepository->Database: Retrieve shares
        activate Database
        Database-->ShareRepository: Shares
        deactivate Database
        ShareRepository-->TimeService: Shares
        deactivate ShareRepository

        TimeService->MeetingRepository: Load invitees' meetings
        activate MeetingRepository
        MeetingRepository->Database: Retrieve meetings
        activate Database
        Database-->MeetingRepository: Meetings
        deactivate Database
        MeetingRepository-->TimeService: Meetings
        deactivate MeetingRepository

        TimeService-->TimeController: Common slots by day
        TimeController-->FindPage: Common slots by day
        FindPage-->Actor: Show common slots by day
    end
end

deactivate TimeService
deactivate TimeController
deactivate FindPage
