title UC-04 - Access Meeting via Guest Invitation

actor "Guest" as Guest
boundary "Guest Invitation Page" as Page
control ":Guest Access Controller" as Controller
control ":Guest Access Service" as Service
participant ":Guest Invitation Repository" as Repository
database ":Database" as Database
participant ":Email Service" as Email

Guest->Page: Open invitation and request access, or reopen the invitation
activate Page
Page->Controller: Start or resume access via Guest invitation
activate Controller
Controller->Service: Check invitation and existing verified Guest access
activate Service
Service->Repository: Read current invitation, verification challenge and Guest access
activate Repository
Repository->Database: Read invitation status/expiry, challenge and access
activate Database
Database-->Repository: Current information / Read failure
Repository-->Service: Current information / Read failure
Service->Service: Check current invitation and Meeting scope (BR-152–BR-157)
alt Invitation is missing or revoked, or the Meeting is no longer open - EX-1
Service-->Controller: Deny access; no protected Meeting content
Service-->Controller: MSG371 - The guest invitation is no longer valid.
Controller-->Page: MSG371 - The guest invitation is no longer valid.
Page-->Guest: MSG371 - The guest invitation is no longer valid.
else Verification/access service is unavailable - EX-3
Service-->Controller: Verification could not be completed; no Guest session
Controller-->Page: Verification unavailable
Page-->Guest: Verification unavailable
else Invitation is current
alt Reopen already verified active Guest session - ALT-1
Service->Service: Reuse access only for this invited Meeting; do not request another code
Service-->Controller: Invited Meeting and allowed Member participation actions
Controller-->Page: Display invited Meeting; subsequent requests recheck access
Page-->Guest: Invited Meeting available
else First access without verified email
Service->Service: Check resend interval and daily code limit for this invitation (BR-371)
alt Previous code was sent less than 1 minute ago - EX-5
Service-->Controller: MSG373 - Wait before requesting another code.
Controller-->Page: MSG373 - Wait before requesting another code.
Page-->Guest: MSG373 - Wait before requesting another code.
else 20 codes were already sent for this invitation within 24 hours - EX-6
Service-->Controller: MSG379 - Too many codes requested. Try again later or contact the Meeting Secretary.
Controller-->Page: MSG379 - Too many codes requested. Try again later or contact the Meeting Secretary.
Page-->Guest: MSG379 - Too many codes requested. Try again later or contact the Meeting Secretary.
else Code request is allowed
Service->Repository: Prepare one-time code for the invited email only; a newer code replaces the previous one (BR-153)
Repository->Database: Save verification challenge
Database-->Repository: Saved / Failure
Repository-->Service: Challenge result
alt Challenge cannot be saved - EX-3
Service-->Controller: Verification unavailable; no Guest session
Controller-->Page: Verification unavailable
Page-->Guest: Verification unavailable
else Challenge saved
Service->Email: Send code to the invited email (BR-153)
activate Email
Email-->Service: Delivery accepted / Failure
alt Email delivery cannot be arranged - EX-3
Service-->Controller: Verification unavailable; no Guest session
Controller-->Page: Verification unavailable
Page-->Guest: Verification unavailable
else Code delivered
Service-->Controller: Request one-time code entry
Controller-->Page: Display invited-email code entry
Page-->Guest: Enter the code sent to the invited email
Guest->Page: Submit the one-time code
Page->Controller: Verify code for this invitation
Controller->Service: Verify code and current invitation
Service->Service: Check correct, unexpired, unused code and invited-email binding (BR-153)
alt Code is incorrect, expired or already used - EX-2
Service-->Controller: MSG126 - Unable to verify the guest invitation. Check the code and try again.
Controller-->Page: MSG126 - Unable to verify the guest invitation. Check the code and try again.
Page-->Guest: MSG126 - Unable to verify the guest invitation. Check the code and try again.
else Code is locked after 5 incorrect entries - EX-4
Service-->Controller: MSG372 - Too many incorrect codes. Request a new code.
Controller-->Page: MSG372 - Too many incorrect codes. Request a new code.
Page-->Guest: MSG372 - Too many incorrect codes. Request a new code.
else Code and invitation are valid
Service->Repository: Consume code and record invited-email verification consistently
Repository->Database: Save verification; recheck current invitation and unused challenge
Database-->Repository: Verification saved / Conflict / Failure
Repository-->Service: Verification result
alt Code was consumed by a concurrent request - EX-2
Service-->Controller: MSG126 - Unable to verify the guest invitation. Check the code and try again.
Controller-->Page: MSG126 - Unable to verify the guest invitation. Check the code and try again.
Page-->Guest: MSG126 - Unable to verify the guest invitation. Check the code and try again.
else Verification cannot be saved - EX-3
Service-->Controller: Verification not completed; no Guest session
Controller-->Page: Verification could not be completed
Page-->Guest: Verification could not be completed
else Invited-email control verified
Service-->Controller: Continue with self-declared display information
Controller-->Page: Show display name and job title entry; invited email remains unchanged
Page-->Guest: Enter display name and optional job title for presentation
Guest->Page: Submit self-declared display information
Page->Controller: Complete invited-Meeting access
Controller->Service: Complete Guest access for this invitation
Service->Service: Check display name is present and display information is valid (BR-180)
Service->Service: Check the display information is not already declared\nwith different values for this invitation (BR-180)
alt Display information is invalid - EX-7
Service-->Controller: MSG377 - Invalid display information.
Controller-->Page: MSG377 - Invalid display information.
Page-->Guest: MSG377 - Invalid display information.
else Display information was already declared with different values - EX-9
Service-->Controller: MSG381 - The display name was already declared.
Controller-->Page: MSG381 - The display name was already declared.
Page-->Guest: MSG381 - The display name was already declared.
else Display information is valid
Service->Service: Keep display fields self-declared, separate from verified email (BR-180)
Service->Repository: Save display information and establish Meeting-scoped Guest access valid for 12 hours (BR-155)
Repository->Database: Save profile and Guest access
Database-->Repository: Saved / Failure
Repository-->Service: Access result
Service->Service: Apply Guest Member participation and permitted additional grants;\nno internal account, system role or Chair/Secretary authority (BR-181)
alt Access cannot be completed - EX-3
Service-->Controller: No successful Guest access
Controller-->Page: Access could not be completed
Page-->Guest: Access could not be completed
else Guest access is established
Service-->Controller: Invited Meeting and allowed Member participation actions
Controller-->Page: Display invited Meeting; subsequent requests recheck access
Page-->Guest: MSG376 - Display information saved; invited Meeting available, email verified, display information self-declared
end
