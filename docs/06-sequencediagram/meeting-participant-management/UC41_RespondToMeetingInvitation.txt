title UC-41 - Respond to Meeting Invitation

actor "Meeting Participant" as Participant
boundary "Meeting Management Page" as MeetingPage
control ":Meeting Participant Controller" as ParticipantController
control ":Meeting Participant Service" as ParticipantService
participant ":Meeting Participant Repository" as ParticipantRepository
database ":Database" as Database

Participant->MeetingPage: Submit Invitation Response
activate MeetingPage
MeetingPage->ParticipantController: Respond to Meeting Invitation
activate ParticipantController
ParticipantController->ParticipantService: respondToInvitation(meetingId, responseRequest)
activate ParticipantService

ParticipantService->ParticipantRepository: Get invitation context, previous delegation, meeting status,\nand optional delegate eligibility (BR-85, BR-86, BR-88)
activate ParticipantRepository
ParticipantRepository->Database: Retrieve meeting, current participant response,\nand selected delegate relationship when supplied
activate Database
Database-->ParticipantRepository: Response context / Not found / Retrieval failed
deactivate Database
ParticipantRepository-->ParticipantService: Response context / Not found / Retrieval failed
deactivate ParticipantRepository

ParticipantService->ParticipantService: Validate invitation owner, Published or InProgress status,\nAccepted, Declined, or valid Delegated response (BR-85, BR-86, BR-88)

alt Invitation can no longer be answered - EX-2
    ParticipantService-->ParticipantController: Invitation is unavailable
    deactivate ParticipantService
    ParticipantController-->MeetingPage: Response rejected
    deactivate ParticipantController
    MeetingPage-->Participant: MSG107 - This meeting invitation can no longer be answered.
else Invitation Response or delegate is invalid - EX-1
    ParticipantService-->ParticipantController: Validation failed
    deactivate ParticipantService
    ParticipantController-->MeetingPage: Invalid response
    deactivate ParticipantController
    MeetingPage-->Participant: MSG106 - Invalid meeting invitation response.\nApplicable validation message
else Invitation Response is valid
    ParticipantService->ParticipantRepository: Atomically save response and response time, set or clear delegate,\nrevoke previous delegate-only access, and preserve Meeting Roles\n(BR-85, BR-86, BR-87)
    activate ParticipantRepository
    ParticipantRepository->Database: Revalidate delegation uniqueness and update response
    activate Database
    Database-->ParticipantRepository: Saved / Delegation conflict / Save failed
    deactivate Database
    ParticipantRepository-->ParticipantService: Saved response and affected users / Conflict / Save failed
    deactivate ParticipantRepository

    alt Delegate became invalid or already represents another participant - EX-1
        ParticipantService-->ParticipantController: Delegation conflict
        deactivate ParticipantService
        ParticipantController-->MeetingPage: Invalid response
        deactivate ParticipantController
        MeetingPage-->Participant: MSG106 - Invalid meeting invitation response.\nApplicable validation message
    else Invitation Response cannot be saved - EX-3
        ParticipantService-->ParticipantController: Save failed
        deactivate ParticipantService
        ParticipantController-->MeetingPage: Response save failed
        deactivate ParticipantController
        MeetingPage-->Participant: MSG108 - Unable to save the meeting invitation response. Please try again.
    else Invitation Response is saved
        ParticipantService->ParticipantService: If meeting is InProgress, re-evaluate affected room access\nand eject only users with no effective room-entry relationship (BR-86)
        ParticipantService-->ParticipantController: Invitation Response recorded
        deactivate ParticipantService
        ParticipantController-->MeetingPage: Response recorded
        deactivate ParticipantController
        MeetingPage-->Participant: MSG105 - Meeting invitation response recorded successfully.
    end
end

deactivate MeetingPage
