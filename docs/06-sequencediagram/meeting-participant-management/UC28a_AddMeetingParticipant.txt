title UC-28a - Add Meeting Participant

actor "Secretary / Chair" as Actor
boundary "Participant Management Page" as ParticipantPage
control ":Participant Controller" as ParticipantController
control ":Participant Service" as ParticipantService
participant ":Participant Repository" as ParticipantRepository
database ":Database" as Database

Actor->ParticipantPage: Add meeting participant
activate ParticipantPage

ParticipantPage->ParticipantController: Add participant (meetingId, selection)
activate ParticipantController

ParticipantController->ParticipantService: addParticipant(meetingId, selection, actor)
activate ParticipantService

ParticipantService->ParticipantRepository: Find meeting and verify actor
activate ParticipantRepository
ParticipantRepository->Database: Retrieve meeting and roster
activate Database
Database-->ParticipantRepository: Meeting and roster
deactivate Database
ParticipantRepository-->ParticipantService: Meeting and roster
deactivate ParticipantRepository

alt Participant information or selection is invalid - EX-1
    ParticipantService-->ParticipantController: MSG97 - Invalid meeting participant information.
    ParticipantController-->ParticipantPage: Return validation errors
    ParticipantPage-->Actor: MSG97 - Invalid meeting participant information.

else Actor is not allowed to manage participants - EX-2
    ParticipantService-->ParticipantController: MSG85 - You do not have permission to perform this action.
    ParticipantController-->ParticipantPage: Return permission error
    ParticipantPage-->Actor: MSG85 - You do not have permission to perform this action.

else Participant management is no longer permitted - EX-3
    ParticipantService-->ParticipantController: MSG98 - The meeting participant list cannot be modified in its current status.
    ParticipantController-->ParticipantPage: Return status error
    ParticipantPage-->Actor: MSG98 - The meeting participant list cannot be modified in its current status.

else Valid selection
    ParticipantService->ParticipantRepository: Save participant(s) together (BR-80-BR-85)
    activate ParticipantRepository
    ParticipantRepository->Database: Insert participant(s)
    activate Database
    Database-->ParticipantRepository: Saved
    deactivate Database
    ParticipantRepository-->ParticipantService: Saved
    deactivate ParticipantRepository

    ParticipantService-->ParticipantController: Participant added
    ParticipantController-->ParticipantPage: MSG96 - Meeting participant added successfully.
    ParticipantPage-->Actor: MSG96 - Meeting participant added successfully.
end

deactivate ParticipantService
deactivate ParticipantController
deactivate ParticipantPage
