title UC-30 - View Participant Response Status

actor "User" as User
boundary "Participants Page" as ParticipantsPage
control ":Participant Controller" as ParticipantController
control ":Participant Service" as ParticipantService
participant ":Participant Repository" as ParticipantRepository
database ":Database" as Database

User->ParticipantsPage: View response status
activate ParticipantsPage

ParticipantsPage->ParticipantController: Get responses (meetingId)
activate ParticipantController

ParticipantController->ParticipantService: getResponses(meetingId, actor)
activate ParticipantService

ParticipantService->ParticipantRepository: Find meeting and check access
activate ParticipantRepository
ParticipantRepository->Database: Retrieve responses and access
activate Database
Database-->ParticipantRepository: Responses / not found
deactivate Database
ParticipantRepository-->ParticipantService: Responses / not found
deactivate ParticipantRepository

alt Responses are not accessible - EX-1
    ParticipantService-->ParticipantController: Not accessible
    ParticipantController-->ParticipantsPage: Return not found
    ParticipantsPage-->User: Responses not accessible

else Accessible
    ParticipantService-->ParticipantController: Responses
    ParticipantController-->ParticipantsPage: Responses
    ParticipantsPage-->User: Show responses (BR-181)
end

deactivate ParticipantService
deactivate ParticipantController
deactivate ParticipantsPage
