title UC-17 - View Meeting List

actor "User" as User
boundary "Meeting List Page" as ListPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
database ":Database" as Database

User->ListPage: Open Meetings
activate ListPage

ListPage->MeetingController: Get meeting list (criteria)
activate MeetingController

MeetingController->MeetingService: getMeetingList(actor, criteria)
activate MeetingService

alt Criteria are invalid - EX-1
    MeetingService-->MeetingController: MSG32 - Tiêu chí danh sách cuộc họp không hợp lệ.
    MeetingController-->ListPage: Return criteria error
    ListPage-->User: MSG32 - Tiêu chí danh sách cuộc họp không hợp lệ.

else Criteria are valid
    MeetingService->MeetingRepository: Find authorized meetings matching criteria
    activate MeetingRepository
    MeetingRepository->Database: Retrieve meetings (BR-29, BR-30, BR-32)
    activate Database
    Database-->MeetingRepository: Meetings
    deactivate Database
    MeetingRepository-->MeetingService: Meetings
    deactivate MeetingRepository

    MeetingService-->MeetingController: Meeting list
    MeetingController-->ListPage: Meeting list
    ListPage-->User: Show meetings (BR-297, BR-321)
end

deactivate MeetingService
deactivate MeetingController
deactivate ListPage
