title UC-14 - Create Meeting

actor "Meeting Organizer" as Organizer
boundary "Meeting Management Page" as MeetingPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
database ":Database" as Database

Organizer->MeetingPage: Submit meeting information\nand initial participants with Meeting Roles
activate MeetingPage

MeetingPage->MeetingController: Create meeting (meetingInfo, participants)
activate MeetingController

MeetingController->MeetingService: createMeeting(meetingInfo, participants)
activate MeetingService

MeetingService->MeetingService: Validate required meeting information, Planned Start Time in the future\nand Planned End Time after Planned Start Time (BR-24, BR-62, BR-162)

MeetingService->MeetingService: Validate participants: 1..100 active internal users, each listed once,\nvalid Meeting Role, exactly one Chair, no Guests (BR-320)

alt Meeting information is invalid - EX-1
    MeetingService-->MeetingController: MSG31 - Invalid meeting information
    deactivate MeetingService
    MeetingController-->MeetingPage: Return validation errors
    deactivate MeetingController
    MeetingPage-->Organizer: MSG31 - Invalid meeting information

else Participants are invalid - EX-3
    activate MeetingController
    activate MeetingService
    MeetingService-->MeetingController: MSG277 - The meeting participant list is not valid
    deactivate MeetingService
    MeetingController-->MeetingPage: Return participant validation errors
    deactivate MeetingController
    MeetingPage-->Organizer: MSG277 - The meeting participant list is not valid

else Meeting information is valid
    activate MeetingController
    activate MeetingService
    MeetingService->MeetingRepository: Create meeting with Draft status and its participants\nwith Pending responses in the same save (BR-26, BR-320)
    activate MeetingRepository

    MeetingRepository->Database: Insert meeting and participants
    activate Database

    alt Meeting cannot be created - EX-2
        Database-->MeetingRepository: Creation failed
        deactivate Database
        MeetingRepository-->MeetingService: Meeting creation failed
        deactivate MeetingRepository
        MeetingService-->MeetingController: MSG35 - Unable to create the meeting.\nPlease try again
        deactivate MeetingService
        MeetingController-->MeetingPage: Return meeting creation failure
        deactivate MeetingController
        MeetingPage-->Organizer: MSG35 - Unable to create the meeting.\nPlease try again

    else Meeting created successfully
        activate Database
        activate MeetingController
        activate MeetingRepository
        activate MeetingService
        Database-->MeetingRepository: Meeting created
        deactivate Database
        MeetingRepository-->MeetingService: Created meeting
        deactivate MeetingRepository
        MeetingService-->MeetingController: Meeting created successfully
        deactivate MeetingService
        MeetingController-->MeetingPage: MSG29 - Meeting created successfully
        deactivate MeetingController
        MeetingPage-->Organizer: MSG29 - Meeting created successfully
    end
end

deactivate MeetingPage
