title UC-18 - Review Meeting Approval

actor "Meeting Approver" as Approver
boundary "Meeting Approval Page" as ApprovalPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
database ":Database" as Database

Approver->ApprovalPage: Review meeting (approve/reject)
activate ApprovalPage

ApprovalPage->MeetingController: Submit decision (meetingId, decision, reason)
activate MeetingController

MeetingController->MeetingService: reviewApproval(meetingId, decision, reason)
activate MeetingService

MeetingService->MeetingRepository: Find meeting and verify approver
activate MeetingRepository
MeetingRepository->Database: Retrieve meeting, status, approver
activate Database
Database-->MeetingRepository: Meeting and approver
deactivate Database
MeetingRepository-->MeetingService: Meeting and approver
deactivate MeetingRepository

alt Rejection reason is missing - EX-1
    MeetingService-->MeetingController: MSG83 - Rejection reason is required.
    MeetingController-->ApprovalPage: Return reason error
    ApprovalPage-->Approver: MSG83 - Rejection reason is required.

else Rejection reason is too long - EX-3
    MeetingService-->MeetingController: MSG84 - Rejection reason must not exceed 1000 characters.
    MeetingController-->ApprovalPage: Return reason error
    ApprovalPage-->Approver: MSG84 - Rejection reason must not exceed 1000 characters.

else Meeting is no longer awaiting approval - EX-2
    MeetingService-->MeetingController: This meeting is no longer awaiting approval.
    MeetingController-->ApprovalPage: Return status error
    ApprovalPage-->Approver: This meeting is no longer awaiting approval.

else Decision valid
    MeetingService->MeetingRepository: Apply decision, update status, record history (BR-022, BR-023)
    activate MeetingRepository
    MeetingRepository->Database: Save decision, status, history, audit
    activate Database
    Database-->MeetingRepository: Saved
    deactivate Database
    MeetingRepository-->MeetingService: Decided
    deactivate MeetingRepository

    MeetingService-->MeetingController: Decision successful
    MeetingController-->ApprovalPage: MSG43/MSG44 - Meeting approved/rejected successfully
    ApprovalPage-->Approver: MSG43/MSG44 - Meeting approved/rejected successfully
end

deactivate MeetingService
deactivate MeetingController
deactivate ApprovalPage
