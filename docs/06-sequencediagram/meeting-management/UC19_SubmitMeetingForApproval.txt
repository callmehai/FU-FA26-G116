title UC-19 - Submit Meeting for Approval

actor "Meeting Organizer" as Organizer
boundary "Meeting Management Page" as MeetingPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
participant ":User Repository" as UserRepository
participant ":Meeting Status History Repository" as MeetingStatusHistoryRepository
participant ":Notification Repository" as NotificationRepository
database ":Database" as Database

Organizer->MeetingPage: Choose Submit for Approval
MeetingPage->MeetingController: Get submission readiness
MeetingController->MeetingService: getSubmissionReadiness(meetingId, organizerId)
MeetingService->MeetingRepository: Get accessible Draft or Rejected meeting
MeetingRepository->Database: Retrieve meeting and current status
Database-->MeetingRepository: Meeting / None
MeetingRepository-->MeetingService: Meeting / None
MeetingService->MeetingService: Validate meeting-level information\nMeeting Sessions are not required (BR-33, BR-55)

alt Meeting-level information is incomplete - EX-1
    MeetingService-->MeetingController: MSG81 - Submission requirements are incomplete
    MeetingController-->MeetingPage: Return missing meeting information
    MeetingPage-->Organizer: MSG81 - Complete the required meeting information
else Meeting-level information is complete
    MeetingService->UserRepository: List active users with MeetingApprover\nexcluding the Organizer (BR-35)
    UserRepository->Database: Query eligible Meeting Approvers
    Database-->UserRepository: Eligible Meeting Approvers
    UserRepository-->MeetingService: Eligible Meeting Approvers
    MeetingService-->MeetingController: Eligible Meeting Approvers
    MeetingController-->MeetingPage: Display eligible Meeting Approvers
    MeetingPage-->Organizer: Show eligible Meeting Approvers

    Organizer->MeetingPage: Select a Meeting Approver and submit
    MeetingPage->MeetingController: Submit meeting for approval
    MeetingController->MeetingService: submitMeetingForApproval(meetingId, approverId)
    MeetingService->MeetingRepository: Lock meeting and get current approval state
    MeetingRepository->Database: Retrieve meeting FOR UPDATE
    Database-->MeetingRepository: Current meeting state
    MeetingRepository-->MeetingService: Current meeting state
    MeetingService->UserRepository: Recheck selected approver eligibility
    UserRepository->Database: Check active status and MeetingApprover capability
    Database-->UserRepository: Approver eligibility result
    UserRepository-->MeetingService: Approver eligibility result

    alt Selected approver is no longer eligible - EX-3
        MeetingService-->MeetingController: MSG82 - Selected Meeting Approver is invalid
        MeetingController-->MeetingPage: Return approver validation failure
        MeetingPage-->Organizer: MSG82 - Select another Meeting Approver
    else Selected approver is eligible
        MeetingService->MeetingService: Recheck Draft or Rejected status

        alt Meeting is no longer Draft or Rejected - EX-2
            MeetingService-->MeetingController: MSG41 - Meeting can no longer be submitted
            MeetingController-->MeetingPage: Return submission restriction
            MeetingPage-->Organizer: MSG41 - Meeting can no longer be submitted
        else Meeting is Draft or Rejected
            MeetingService->MeetingRepository: Assign approver and set WaitingApproval\n(BR-34, BR-35)
            MeetingRepository->Database: Update meeting and assignment

            alt Submission cannot be completed - EX-4
                Database-->MeetingRepository: Transaction failed
                MeetingRepository-->MeetingService: Submission failed
                MeetingService-->MeetingController: MSG42 - Unable to submit for approval
                MeetingController-->MeetingPage: Return submission failure
                MeetingPage-->Organizer: MSG42 - Unable to submit for approval
            else Meeting submitted successfully
                Database-->MeetingRepository: Meeting moved to WaitingApproval
                MeetingRepository-->MeetingService: Assignment and status stored
                MeetingService->MeetingStatusHistoryRepository: Append SubmitForApproval history\nwith assigned approver (BR-38)
                MeetingStatusHistoryRepository->Database: Insert lifecycle history
                Database-->MeetingStatusHistoryRepository: History recorded
                MeetingStatusHistoryRepository-->MeetingService: Transition recorded
                MeetingService->NotificationRepository: Create approval notification
                NotificationRepository->Database: Insert notification
                Database-->NotificationRepository: Notification created
                NotificationRepository-->MeetingService: Notification created
                MeetingService-->MeetingController: MSG78 - Meeting submitted successfully
                MeetingController-->MeetingPage: MSG78 - Meeting submitted successfully
                MeetingPage-->Organizer: MSG78 - Meeting submitted successfully
            end
        end
    end
end
