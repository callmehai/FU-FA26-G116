title UC-21 - Start Meeting

actor "Chair / Secretary" as Starter
boundary "Meeting Management Page" as MeetingPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
control ":Notification Service" as NotificationService
database ":Database" as Database

Starter->MeetingPage: Start meeting
activate MeetingPage

MeetingPage->MeetingController: Start meeting (meetingId)
activate MeetingController

MeetingController->MeetingService: startMeeting(meetingId, starter)
activate MeetingService

MeetingService->MeetingRepository: Find meeting and verify starter
activate MeetingRepository
MeetingRepository->Database: Retrieve meeting, status, chair/secretary
activate Database
Database-->MeetingRepository: Meeting and participants
deactivate Database
MeetingRepository-->MeetingService: Meeting and participants
deactivate MeetingRepository

alt Meeting cannot be started - EX-1
    MeetingService-->MeetingController: MSG112 - This meeting cannot be started.
    MeetingController-->MeetingPage: Return start error
    MeetingPage-->Starter: MSG112 - This meeting cannot be started.

else Eligible
    MeetingService->MeetingRepository: Change status to InProgress, record start time (BR-38, BR-131, BR-445)
    activate MeetingRepository
    MeetingRepository->Database: Save status and history
    activate Database
    Database-->MeetingRepository: Started
    deactivate Database
    MeetingRepository-->MeetingService: Started
    deactivate MeetingRepository

    MeetingService->NotificationService: Notify participants (BR-164, BR-322)
    activate NotificationService
    NotificationService-->MeetingService: Notified
    deactivate NotificationService

    MeetingService-->MeetingController: Start successful
    MeetingController-->MeetingPage: MSG110 - Meeting started successfully.
    MeetingPage-->Starter: MSG110 - Meeting started successfully.
end

deactivate MeetingService
deactivate MeetingController
deactivate MeetingPage
