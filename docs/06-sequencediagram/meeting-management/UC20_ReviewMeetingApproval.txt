title UC-20 - Review Meeting Approval

actor "Meeting Approver" as Approver
boundary "Meeting Management Page" as MeetingPage
control ":Meeting Controller" as MeetingController
control ":Meeting Service" as MeetingService
participant ":Meeting Repository" as MeetingRepository
participant ":Meeting Status History Repository" as MeetingStatusHistoryRepository
database ":Database" as Database

Approver->MeetingPage: Submit Approve or Reject decision
MeetingPage->MeetingController: Review meeting approval
MeetingController->MeetingService: reviewMeetingApproval(meetingId, decision, rejectionReason)
MeetingService->MeetingRepository: Lock meeting and get current approval state
MeetingRepository->Database: Retrieve status and assigned approver FOR UPDATE
Database-->MeetingRepository: Current approval state
MeetingRepository-->MeetingService: Current approval state
MeetingService->MeetingService: Verify current assigned approver, active account\nand MeetingApprover capability (BR-35)

alt Approver is no longer authorized - EX-4
    MeetingService-->MeetingController: MSG85 - User is no longer authorized
    MeetingController-->MeetingPage: Return approval access denial
    MeetingPage-->Approver: MSG85 - You can no longer review this meeting
else Approver is authorized
    MeetingService->MeetingService: Verify WaitingApproval status

    alt Meeting is no longer WaitingApproval - EX-2
        MeetingService-->MeetingController: MSG63 - Meeting is no longer awaiting approval
        MeetingController-->MeetingPage: Return status conflict
        MeetingPage-->Approver: MSG63 - Meeting is no longer awaiting approval
    else Meeting is WaitingApproval
        MeetingService->MeetingService: For Reject, trim rejection reason\nand validate 1-1,000 characters

        alt Reject reason is empty after trim - EX-1
            MeetingService-->MeetingController: MSG83 - Rejection reason is required
            MeetingController-->MeetingPage: Return required reason validation
            MeetingPage-->Approver: MSG83 - Rejection reason is required
        else Reject reason exceeds 1,000 characters - EX-1
            MeetingService-->MeetingController: MSG84 - Rejection reason is too long
            MeetingController-->MeetingPage: Return reason length validation
            MeetingPage-->Approver: MSG84 - Rejection reason must not exceed 1,000 characters
        else Approval decision is valid
            MeetingService->MeetingRepository: Apply WaitingApproval -> Approved / Rejected\n(BR-36)
            MeetingRepository->Database: Update meeting status

            alt Approval decision cannot be completed - EX-3
                Database-->MeetingRepository: Transaction failed
                MeetingRepository-->MeetingService: Approval decision failed
                MeetingService-->MeetingController: MSG88 - Unable to complete approval decision
                MeetingController-->MeetingPage: Return approval decision failure
                MeetingPage-->Approver: MSG88 - Unable to complete approval decision
            else Approval decision completed
                Database-->MeetingRepository: Meeting status updated
                MeetingRepository-->MeetingService: Approval decision applied

                alt Decision is Approve
                    MeetingService->MeetingStatusHistoryRepository: Append Approve history (BR-38)
                    MeetingStatusHistoryRepository->Database: Insert lifecycle history
                    Database-->MeetingStatusHistoryRepository: History recorded
                    MeetingStatusHistoryRepository-->MeetingService: Approval recorded
                    MeetingService-->MeetingController: MSG43 - Meeting approved successfully
                    MeetingController-->MeetingPage: MSG43 - Meeting approved successfully
                    MeetingPage-->Approver: MSG43 - Meeting approved successfully
                else Decision is Reject - AF-1
                    MeetingService->MeetingStatusHistoryRepository: Append Reject history with trimmed reason\n(BR-38)
                    MeetingStatusHistoryRepository->Database: Insert lifecycle history
                    Database-->MeetingStatusHistoryRepository: History recorded
                    MeetingStatusHistoryRepository-->MeetingService: Rejection recorded
                    MeetingService-->MeetingController: MSG44 - Meeting rejected successfully
                    MeetingController-->MeetingPage: MSG44 - Meeting rejected successfully
                    MeetingPage-->Approver: MSG44 - Meeting rejected successfully
                end
            end
        end
    end
end
