title UC-23c - Delete Agenda Item

actor "Secretary" as Secretary
boundary "Meeting Agenda Page" as AgendaPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Agenda Repository" as AgendaRepository
database ":Database" as Database

Secretary->AgendaPage: Delete agenda item
activate AgendaPage

AgendaPage->AgendaController: Delete item (meetingId, itemId)
activate AgendaController

AgendaController->AgendaService: deleteAgendaItem(meetingId, itemId)
activate AgendaService

AgendaService->AgendaRepository: Find item and verify secretary
activate AgendaRepository
AgendaRepository->Database: Retrieve item and meeting
activate Database
Database-->AgendaRepository: Item and meeting
deactivate Database
AgendaRepository-->AgendaService: Item and meeting
deactivate AgendaRepository

alt Agenda planning no longer permitted - EX-1
    AgendaService-->AgendaController: MSG67 - The agenda for this meeting can no longer be modified.
    AgendaController-->AgendaPage: Return planning error
    AgendaPage-->Secretary: MSG67 - The agenda for this meeting can no longer be modified.

else Agenda item has already started - EX-2
    AgendaService-->AgendaController: MSG142 - Only Pending agenda items can be deleted.
    AgendaController-->AgendaPage: Return status error
    AgendaPage-->Secretary: MSG142 - Only Pending agenda items can be deleted.

else Eligible
    AgendaService->AgendaRepository: Remove pending item and its links (BR-283)
    activate AgendaRepository
    AgendaRepository->Database: Delete agenda item
    activate Database
    Database-->AgendaRepository: Deleted
    deactivate Database
    AgendaRepository-->AgendaService: Deleted
    deactivate AgendaRepository

    AgendaService-->AgendaController: Item deleted successfully
    AgendaController-->AgendaPage: MSG62 - Agenda item deleted successfully.
    AgendaPage-->Secretary: MSG62 - Agenda item deleted successfully.
end

deactivate AgendaService
deactivate AgendaController
deactivate AgendaPage
