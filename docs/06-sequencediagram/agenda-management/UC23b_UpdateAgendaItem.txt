title UC-23b - Update Agenda Item

actor "Secretary" as Secretary
boundary "Meeting Agenda Page" as AgendaPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Agenda Repository" as AgendaRepository
database ":Database" as Database

Secretary->AgendaPage: Update agenda item
activate AgendaPage

AgendaPage->AgendaController: Update item (meetingId, itemId, changes)
activate AgendaController

AgendaController->AgendaService: updateAgendaItem(meetingId, itemId, changes)
activate AgendaService

AgendaService->AgendaRepository: Find item and verify secretary
activate AgendaRepository
AgendaRepository->Database: Retrieve item and meeting
activate Database
Database-->AgendaRepository: Item and meeting
deactivate Database
AgendaRepository-->AgendaService: Item and meeting
deactivate AgendaRepository

alt Invalid agenda item information - EX-1
    AgendaService-->AgendaController: MSG66 - Invalid agenda item information.
    AgendaController-->AgendaPage: Return validation errors
    AgendaPage-->Secretary: MSG66 - Invalid agenda item information.

else Editing no longer permitted - EX-2
    AgendaService-->AgendaController: MSG67 - The agenda for this meeting can no longer be modified.
    AgendaController-->AgendaPage: Return planning error
    AgendaPage-->Secretary: MSG67 - The agenda for this meeting can no longer be modified.

else Valid update
    AgendaService->AgendaRepository: Save changes preserving status and timestamps (BR-68)
    activate AgendaRepository
    AgendaRepository->Database: Update agenda item
    activate Database
    Database-->AgendaRepository: Updated
    deactivate Database
    AgendaRepository-->AgendaService: Updated
    deactivate AgendaRepository

    AgendaService-->AgendaController: Item updated successfully
    AgendaController-->AgendaPage: MSG61 - Agenda item updated successfully.
    AgendaPage-->Secretary: MSG61 - Agenda item updated successfully.
end

deactivate AgendaService
deactivate AgendaController
deactivate AgendaPage
