title UC-32 - Update Agenda Item

actor "Secretary" as Secretary
boundary "Meeting Management Page" as MeetingPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Meeting Repository" as MeetingRepository
participant ":Meeting Participant Repository" as MeetingParticipantRepository
participant ":Meeting Session Repository" as MeetingSessionRepository
participant ":Agenda Item Repository" as AgendaItemRepository
participant ":Document Repository" as DocumentRepository
database ":Database" as Database

Secretary->MeetingPage: Submit updated agenda item information
activate MeetingPage

MeetingPage->AgendaController: Update Agenda Item
activate AgendaController

AgendaController->AgendaService: updateAgendaItem(meetingId, sessionId, agendaItemId, secretaryId, agendaInfo, documentIds)
activate AgendaService

AgendaService->MeetingSessionRepository: Get selected Meeting Session
activate MeetingSessionRepository
MeetingSessionRepository->Database: Retrieve Meeting Session
activate Database
Database-->MeetingSessionRepository: Meeting Session
deactivate Database
MeetingSessionRepository-->AgendaService: Meeting Session
deactivate MeetingSessionRepository

AgendaService->MeetingRepository: Get parent meeting
activate MeetingRepository
MeetingRepository->Database: Retrieve parent meeting
activate Database
Database-->MeetingRepository: Meeting
deactivate Database
MeetingRepository-->AgendaService: Meeting
deactivate MeetingRepository

AgendaService->MeetingParticipantRepository: Verify Secretary assignment to parent meeting (BR-65)
activate MeetingParticipantRepository
MeetingParticipantRepository->Database: Find Secretary assignment
activate Database
Database-->MeetingParticipantRepository: Assignment result
deactivate Database
MeetingParticipantRepository-->AgendaService: Assignment result
deactivate MeetingParticipantRepository

AgendaService->AgendaItemRepository: Get selected Agenda Item
activate AgendaItemRepository
AgendaItemRepository->Database: Retrieve selected Agenda Item
activate Database
Database-->AgendaItemRepository: Agenda Item
deactivate Database
AgendaItemRepository-->AgendaService: Agenda Item
deactivate AgendaItemRepository

opt Meeting documents are selected
    AgendaService->DocumentRepository: Get selected documents available to parent meeting (BR-66)
    activate DocumentRepository
    DocumentRepository->Database: Retrieve selected meeting documents
    activate Database
    Database-->DocumentRepository: Available selected documents
    deactivate Database
    DocumentRepository-->AgendaService: Available selected documents
    deactivate DocumentRepository
end

AgendaService->AgendaService: Validate required title, positive planned duration,\noptional presenter and description, and selected documents (BR-66)

alt Invalid Agenda Item information - EX-1
    AgendaService-->AgendaController: MSG66 - Invalid agenda item information.\nApplicable field message(s)
    deactivate AgendaService
    AgendaController-->MeetingPage: MSG66 - Invalid agenda item information.\nApplicable field message(s)
    deactivate AgendaController
    MeetingPage-->Secretary: MSG66 - Invalid agenda item information.\nApplicable field message(s):\nAgenda item title is required.\nPlanned duration must be greater than 0.\nOne or more selected documents are not available to this meeting.

else Agenda Item information is valid
    AgendaService->AgendaService: Verify session and item ownership, Pending Agenda Item,\nassigned Secretary, Planned session and parent meeting permits agenda planning;\nPublished or InProgress alone does not block planning (BR-65, BR-68, BR-74)

    alt Agenda Item can no longer be updated - EX-2
        AgendaService-->AgendaController: MSG67 - The agenda for this meeting session can no longer be modified.
        deactivate AgendaService
        AgendaController-->MeetingPage: MSG67 - The agenda for this meeting session can no longer be modified.
        deactivate AgendaController
        MeetingPage-->Secretary: MSG67 - The agenda for this meeting session can no longer be modified.\nAgenda Item remains unchanged

    else Agenda modification is permitted
        AgendaService->AgendaItemRepository: Save updated title, planned duration, optional presenter,\noptional description and document associations (BR-68)
        activate AgendaItemRepository
        AgendaItemRepository->Database: Update Agenda Item information and document associations
        activate Database
        Database-->AgendaItemRepository: Change saved / Save failed without changing Agenda Item
        deactivate Database
        AgendaItemRepository-->AgendaService: Updated Agenda Item / Save failed
        deactivate AgendaItemRepository

        alt Agenda Item cannot be updated - EX-3
            AgendaService-->AgendaController: MSG69 - Unable to update the agenda item. Please try again.
            deactivate AgendaService
            AgendaController-->MeetingPage: MSG69 - Unable to update the agenda item. Please try again.
            deactivate AgendaController
            MeetingPage-->Secretary: MSG69 - Unable to update the agenda item. Please try again.\nAgenda Item remains unchanged

        else Agenda Item is updated
            AgendaService-->AgendaController: Agenda Item updated successfully
            deactivate AgendaService
            AgendaController-->MeetingPage: MSG61 - Agenda item updated successfully.\nUpdated session agenda
            deactivate AgendaController
            MeetingPage-->Secretary: MSG61 - Agenda item updated successfully.\nShow updated session agenda
        end
    end
end

deactivate MeetingPage
