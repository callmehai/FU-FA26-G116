title UC-25 - Complete Agenda Item

actor "Chair" as Chair
boundary "Meeting Agenda Page" as AgendaPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Agenda Repository" as AgendaRepository
database ":Database" as Database

Chair->AgendaPage: Complete agenda item
activate AgendaPage

AgendaPage->AgendaController: Complete item (meetingId, itemId)
activate AgendaController

AgendaController->AgendaService: completeAgendaItem(meetingId, itemId)
activate AgendaService

AgendaService->AgendaRepository: Find item and verify chair
activate AgendaRepository
AgendaRepository->Database: Retrieve item and meeting
activate Database
Database-->AgendaRepository: Item and meeting
deactivate Database
AgendaRepository-->AgendaService: Item and meeting
deactivate AgendaRepository

alt Agenda item cannot be completed - EX-1
    AgendaService-->AgendaController: MSG74 - This agenda item cannot be completed.
    AgendaController-->AgendaPage: Return status error
    AgendaPage-->Chair: MSG74 - This agenda item cannot be completed.

else Eligible
    AgendaService->AgendaRepository: Set item Done and record end time (BR-70, BR-72)
    activate AgendaRepository
    AgendaRepository->Database: Update agenda item
    activate Database
    Database-->AgendaRepository: Completed
    deactivate Database
    AgendaRepository-->AgendaService: Completed
    deactivate AgendaRepository

    AgendaService-->AgendaController: Item completed
    AgendaController-->AgendaPage: MSG65 - Agenda item completed successfully.
    AgendaPage-->Chair: MSG65 - Agenda item completed successfully.
end

deactivate AgendaService
deactivate AgendaController
deactivate AgendaPage
