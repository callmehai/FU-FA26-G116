title UC-24 - Set Current Agenda Item

actor "Chair" as Chair
boundary "Meeting Management Page" as MeetingPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Meeting Repository" as MeetingRepository
participant ":Meeting Participant Repository" as MeetingParticipantRepository
participant ":Agenda Item Repository" as AgendaItemRepository
database ":Database" as Database

Chair->MeetingPage: Set Current Agenda Item
activate MeetingPage
MeetingPage->AgendaController: Set Current Agenda Item
activate AgendaController
AgendaController->AgendaService: setCurrentAgendaItem(meetingId, agendaItemId, chairId)
activate AgendaService

AgendaService->MeetingRepository: Get selected Meeting and current status
activate MeetingRepository
MeetingRepository->Database: Get selected Meeting and current status
activate Database
Database-->MeetingRepository: Meeting / Not found
deactivate Database
MeetingRepository-->AgendaService: Meeting / Not found
deactivate MeetingRepository

AgendaService->MeetingParticipantRepository: Check active current Chair assignment
activate MeetingParticipantRepository
MeetingParticipantRepository->Database: Check active current Chair assignment
activate Database
Database-->MeetingParticipantRepository: Active Chair / Not eligible
deactivate Database
MeetingParticipantRepository-->AgendaService: Active Chair / Not eligible
deactivate MeetingParticipantRepository

AgendaService->AgendaItemRepository: Get selected Item and Meeting membership
activate AgendaItemRepository
AgendaItemRepository->Database: Get selected Item and Meeting membership
activate Database
Database-->AgendaItemRepository: Item and current status / Not found
deactivate Database
AgendaItemRepository-->AgendaService: Item and current status / Not found
deactivate AgendaItemRepository

AgendaService->AgendaService: Verify active Chair, Meeting InProgress,\nItem belongs to selected Meeting and Item is Pending (BR-64, BR-69)
alt Item cannot become current - EX-1
    AgendaService-->AgendaController: MSG73 - This agenda item cannot be set as current.
    AgendaController-->MeetingPage: MSG73 - This agenda item cannot be set as current.
    MeetingPage-->Chair: MSG73 - This agenda item cannot be set as current.
else Initial conditions valid
    AgendaService->AgendaItemRepository: Get any InProgress Item of the Meeting (BR-71)
    activate AgendaItemRepository
    AgendaItemRepository->Database: Get any InProgress Item of the Meeting (BR-71)
    activate Database
    Database-->AgendaItemRepository: Current Item / None
    deactivate Database
    AgendaItemRepository-->AgendaService: Current Item / None
    deactivate AgendaItemRepository

    alt Another Item is InProgress - EX-2
        AgendaService-->AgendaController: MSG72 - Another agenda item is already in progress.\nComplete it before starting another agenda item.
        AgendaController-->MeetingPage: MSG72 - Another agenda item is already in progress.\nComplete it before starting another agenda item.
        MeetingPage-->Chair: MSG72 - Another agenda item is already in progress.\nComplete it before starting another agenda item.
    else No Item is current; position of the selected Item does not matter
        AgendaService->AgendaItemRepository: Recheck Item is Pending and no Item is InProgress, then save InProgress\nwith actual start time as one change; allow only one concurrent start (BR-70, BR-71, BR-72)
        activate AgendaItemRepository
        AgendaItemRepository->Database: Recheck Item is Pending and no Item is InProgress, then save InProgress\nwith actual start time as one change; allow only one concurrent start (BR-70, BR-71, BR-72)
        activate Database
        Database-->AgendaItemRepository: Started / Another Item started / Save failed
        deactivate Database
        AgendaItemRepository-->AgendaService: Started / Another Item started / Save failed
        deactivate AgendaItemRepository

        alt Another Item became current - EX-2
            AgendaService-->AgendaController: MSG72 - Another agenda item is already in progress.\nComplete it before starting another agenda item.
            AgendaController-->MeetingPage: MSG72 - Another agenda item is already in progress.\nComplete it before starting another agenda item.
            MeetingPage-->Chair: MSG72 - Another agenda item is already in progress.\nComplete it before starting another agenda item.
        else Status or actual start cannot be saved - EX-3
            AgendaService-->AgendaController: MSG75 - Unable to set the current agenda item. Please try again.\nPrevious Agenda and timestamps preserved
            AgendaController-->MeetingPage: MSG75 - Unable to set the current agenda item. Please try again.\nPrevious Agenda and timestamps preserved
            MeetingPage-->Chair: MSG75 - Unable to set the current agenda item. Please try again.\nPrevious Agenda and timestamps preserved
        else Item started successfully
            AgendaService->AgendaService: Automatically refresh the complete Agenda\nfor currently authorized viewers (BR-73)
            AgendaService-->AgendaController: MSG64 - Current agenda item updated successfully.
            AgendaController-->MeetingPage: MSG64 - Current agenda item updated successfully.
            MeetingPage-->Chair: MSG64 - Current agenda item updated successfully.
        end
    end
end

deactivate AgendaService
deactivate AgendaController
deactivate MeetingPage
