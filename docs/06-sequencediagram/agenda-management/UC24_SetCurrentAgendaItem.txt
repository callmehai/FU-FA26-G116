title UC-24 - Set Current Agenda Item

actor "Chair" as Chair
boundary "Meeting Agenda Page" as AgendaPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Agenda Repository" as AgendaRepository
database ":Database" as Database

Chair->AgendaPage: Set current agenda item
activate AgendaPage

AgendaPage->AgendaController: Set current (meetingId, itemId)
activate AgendaController

AgendaController->AgendaService: setCurrentAgendaItem(meetingId, itemId)
activate AgendaService

AgendaService->AgendaRepository: Find item and verify chair
activate AgendaRepository
AgendaRepository->Database: Retrieve item and meeting
activate Database
Database-->AgendaRepository: Item and meeting
deactivate Database
AgendaRepository-->AgendaService: Item and meeting
deactivate AgendaRepository

alt Agenda item cannot become current - EX-1
    AgendaService-->AgendaController: MSG73 - Agenda item cannot become current.
    AgendaController-->AgendaPage: Return status error
    AgendaPage-->Chair: MSG73 - Agenda item cannot become current.

else Another agenda item is in progress - EX-2
    AgendaService-->AgendaController: MSG72 - Another agenda item is already in progress. Complete it before starting another agenda item.
    AgendaController-->AgendaPage: Return conflict
    AgendaPage-->Chair: MSG72 - Another agenda item is already in progress. Complete it before starting another agenda item.

else Eligible
    AgendaService->AgendaRepository: Set item InProgress and record start time (BR-70, BR-71)
    activate AgendaRepository
    AgendaRepository->Database: Update agenda item
    activate Database
    Database-->AgendaRepository: Updated
    deactivate Database
    AgendaRepository-->AgendaService: Updated
    deactivate AgendaRepository

    AgendaService-->AgendaController: Current item updated
    AgendaController-->AgendaPage: MSG64 - Current agenda item updated successfully.
    AgendaPage-->Chair: MSG64 - Current agenda item updated successfully.
end

deactivate AgendaService
deactivate AgendaController
deactivate AgendaPage
