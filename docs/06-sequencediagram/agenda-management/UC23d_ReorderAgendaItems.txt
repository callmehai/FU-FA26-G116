title UC-23d - Reorder Agenda Items

actor "Secretary" as Secretary
boundary "Meeting Management Page" as MeetingPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Meeting Repository" as MeetingRepository
participant ":Meeting Participant Repository" as MeetingParticipantRepository
participant ":Agenda Item Repository" as AgendaItemRepository
database ":Database" as Database

Secretary->MeetingPage: Reorder Agenda Items
activate MeetingPage
MeetingPage->AgendaController: Reorder Agenda Items
activate AgendaController
AgendaController->AgendaService: reorderAgendaItems(meetingId, secretaryId, orderedItemIds)
activate AgendaService

AgendaService->MeetingRepository: Get selected Meeting and current status
activate MeetingRepository
MeetingRepository->Database: Get selected Meeting and current status
activate Database
Database-->MeetingRepository: Meeting / Not found
deactivate Database
MeetingRepository-->AgendaService: Meeting / Not found
deactivate MeetingRepository

AgendaService->MeetingParticipantRepository: Check active current Secretary assignment
activate MeetingParticipantRepository
MeetingParticipantRepository->Database: Check active current Secretary assignment
activate Database
Database-->MeetingParticipantRepository: Active Secretary / Not eligible
deactivate Database
MeetingParticipantRepository-->AgendaService: Active Secretary / Not eligible
deactivate MeetingParticipantRepository

AgendaService->AgendaService: Verify Secretary and permitted Meeting status (BR-65, BR-74)
alt Reordering no longer permitted - EX-1
    AgendaService-->AgendaController: MSG67 - The agenda for this meeting can no longer be modified.
    AgendaController-->MeetingPage: MSG67 - The agenda for this meeting can no longer be modified.
    MeetingPage-->Secretary: MSG67 - The agenda for this meeting can no longer be modified.
else Reordering permitted
    AgendaService->AgendaItemRepository: Get complete latest Meeting Agenda and positions
    activate AgendaItemRepository
    AgendaItemRepository->Database: Get complete latest Meeting Agenda and positions
    activate Database
    Database-->AgendaItemRepository: Current ordered Agenda
    deactivate Database
    AgendaItemRepository-->AgendaService: Current ordered Agenda
    deactivate AgendaItemRepository

    AgendaService->AgendaService: Validate each current Item appears exactly once, whatever its status;\nno foreign Items; request matches the latest Agenda (BR-64, BR-238)
    alt Invalid or outdated Agenda order - EX-2
        AgendaService-->AgendaController: MSG143 - The agenda order is invalid or out of date.\nRefresh the agenda and try again.
        AgendaController-->MeetingPage: MSG143 - The agenda order is invalid or out of date.\nRefresh the agenda and try again.
        MeetingPage-->Secretary: MSG143 - The agenda order is invalid or out of date.\nRefresh the agenda and try again.
        MeetingPage->MeetingPage: Refresh the complete Agenda
    else Agenda order valid
        AgendaService->AgendaItemRepository: Recheck latest Agenda and save the new order together;\nkeep Item membership, execution status and actual times unchanged (BR-238)
        activate AgendaItemRepository
        AgendaItemRepository->Database: Recheck latest Agenda and save the new order together;\nkeep Item membership, execution status and actual times unchanged (BR-238)
        activate Database
        Database-->AgendaItemRepository: Change saved / Save failed; previous Agenda preserved
        deactivate Database
        AgendaItemRepository-->AgendaService: Change saved / Save failed; previous Agenda preserved
        deactivate AgendaItemRepository

        alt Change cannot be saved - EX-3
            AgendaService-->AgendaController: MSG71 - Unable to update the agenda order. Please try again.
            AgendaController-->MeetingPage: MSG71 - Unable to update the agenda order. Please try again.
            MeetingPage-->Secretary: MSG71 - Unable to update the agenda order. Please try again.
        else Change saved successfully
            AgendaService->AgendaService: Automatically refresh the complete saved Agenda\nfor currently authorized users viewing this Meeting (BR-73)
            AgendaService-->AgendaController: MSG63 - Agenda order updated successfully.
            AgendaController-->MeetingPage: MSG63 - Agenda order updated successfully.
            MeetingPage-->Secretary: MSG63 - Agenda order updated successfully.
        end
    end
end

deactivate AgendaService
deactivate AgendaController
deactivate MeetingPage
