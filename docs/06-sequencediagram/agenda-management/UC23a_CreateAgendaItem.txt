title UC-23a - Create Agenda Item

actor "Secretary" as Secretary
boundary "Meeting Agenda Page" as AgendaPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Agenda Repository" as AgendaRepository
database ":Database" as Database

Secretary->AgendaPage: Create agenda item
activate AgendaPage

AgendaPage->AgendaController: Create item (meetingId, itemInfo)
activate AgendaController

AgendaController->AgendaService: createAgendaItem(meetingId, itemInfo)
activate AgendaService

AgendaService->AgendaRepository: Find meeting and verify secretary
activate AgendaRepository
AgendaRepository->Database: Retrieve meeting and secretary
activate Database
Database-->AgendaRepository: Meeting and secretary
deactivate Database
AgendaRepository-->AgendaService: Meeting and secretary
deactivate AgendaRepository

alt Invalid agenda item information - EX-1
    AgendaService-->AgendaController: MSG66 - Invalid agenda item information.
    AgendaController-->AgendaPage: Return validation errors
    AgendaPage-->Secretary: MSG66 - Invalid agenda item information.

else Agenda planning no longer permitted - EX-2
    AgendaService-->AgendaController: MSG67 - The agenda for this meeting can no longer be modified.
    AgendaController-->AgendaPage: Return planning error
    AgendaPage-->Secretary: MSG67 - The agenda for this meeting can no longer be modified.

else Valid input
    AgendaService->AgendaRepository: Create pending item after last position (BR-67)
    activate AgendaRepository
    AgendaRepository->Database: Insert agenda item
    activate Database
    Database-->AgendaRepository: Created
    deactivate Database
    AgendaRepository-->AgendaService: Created
    deactivate AgendaRepository

    AgendaService-->AgendaController: Item created successfully
    AgendaController-->AgendaPage: MSG60 - Agenda item created successfully.
    AgendaPage-->Secretary: MSG60 - Agenda item created successfully.
end

deactivate AgendaService
deactivate AgendaController
deactivate AgendaPage
