title UC-27 - Record Agenda Item Conclusion

actor "Chair / Secretary" as Actor
boundary "Meeting Agenda Page" as AgendaPage
control ":Agenda Controller" as AgendaController
control ":Agenda Service" as AgendaService
participant ":Agenda Repository" as AgendaRepository
database ":Database" as Database

Actor->AgendaPage: Save agenda item conclusion
activate AgendaPage

AgendaPage->AgendaController: Save conclusion (meetingId, itemId, text)
activate AgendaController

AgendaController->AgendaService: saveConclusion(meetingId, itemId, text, actor)
activate AgendaService

AgendaService->AgendaRepository: Find item and verify actor
activate AgendaRepository
AgendaRepository->Database: Retrieve item and meeting
activate Database
Database-->AgendaRepository: Item and meeting
deactivate Database
AgendaRepository-->AgendaService: Item and meeting
deactivate AgendaRepository

alt Conclusion is blank or too long - EX-1
    AgendaService-->AgendaController: MSG272 - Enter a conclusion of up to 2,000 characters.
    AgendaController-->AgendaPage: Return validation error
    AgendaPage-->Actor: MSG272 - Enter a conclusion of up to 2,000 characters.

else Conclusion can no longer be changed - EX-2
    AgendaService-->AgendaController: MSG273 - The conclusion of this agenda item can no longer be changed.
    AgendaController-->AgendaPage: Return status error
    AgendaPage-->Actor: MSG273 - The conclusion of this agenda item can no longer be changed.

else Valid input
    AgendaService->AgendaRepository: Save conclusion with actor and time (BR-066, BR-067, UC-27)
    activate AgendaRepository
    AgendaRepository->Database: Update agenda item conclusion
    activate Database
    Database-->AgendaRepository: Saved
    deactivate Database
    AgendaRepository-->AgendaService: Saved
    deactivate AgendaRepository

    AgendaService-->AgendaController: Conclusion saved
    AgendaController-->AgendaPage: MSG271 - Agenda item conclusion saved.
    AgendaPage-->Actor: MSG271 - Agenda item conclusion saved.
end

deactivate AgendaService
deactivate AgendaController
deactivate AgendaPage
