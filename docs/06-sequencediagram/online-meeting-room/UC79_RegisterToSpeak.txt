title UC-79 - Register to Speak

actor "Participant" as Actor
boundary "Online Meeting Room Page" as Page
control ":Meeting Room Controller" as RoomController
control ":Meeting Room Service" as RoomService
participant ":Room Service" as RoomProvider
database ":Database" as Database

Actor->Page: Raise hand to speak
activate Page

Page->RoomController: Register to speak
activate RoomController

RoomController->RoomService: registerToSpeak(meetingId, actorId)
activate RoomService

RoomService->RoomProvider: Check meeting is in progress and actor has no open request
activate RoomProvider
RoomProvider-->RoomService: Eligible / not eligible
deactivate RoomProvider

alt Meeting is no longer in progress - EX-1
    RoomService-->RoomController: MSG117 - The meeting room opens only while the meeting is in progress.
    RoomController-->Page: MSG117 - The meeting room opens only while the meeting is in progress.
    Page-->Actor: MSG117 - The meeting room opens only while the meeting is in progress.

else Actor already has an open request - EX-2
    RoomService-->RoomController: Hand stays raised
    RoomController-->Page: Hand stays raised
    Page-->Actor: Request already open

else Actor is no longer the chair - EX-3
    RoomService-->RoomController: Chair controls unavailable
    RoomController-->Page: Chair controls unavailable
    Page-->Actor: Chair role changed

else Eligible
    RoomService->RoomProvider: Add request to queue
    activate RoomProvider
    RoomProvider-->RoomService: Queued
    deactivate RoomProvider

    RoomService-->RoomController: Hand raised
    RoomController-->Page: Hand raised
    Page-->Actor: Raised hand shown
end

deactivate RoomService
deactivate RoomController
deactivate Page
