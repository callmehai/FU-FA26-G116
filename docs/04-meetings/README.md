# 04 · Biên bản họp nhóm

Đặt tên: `YYYY-MM-DD-chu-de.md`, ví dụ `2026-09-25-chot-pham-vi.md`.

Mỗi biên bản nên có: ngày, người tham dự, nội dung bàn, **quyết định đã chốt**, việc được giao
(ai — làm gì — hạn nào). Quyết định kỹ thuật lớn thì ngoài biên bản còn viết thêm một ADR trong
[../05-decisions/](../05-decisions/).
